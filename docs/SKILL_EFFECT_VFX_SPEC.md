> **문서 상태:** 상세 설계 v1.2 · 2026-10-02. 게임 코드 구현 전의 기준안.  
> **관계:** [전체 시스템 설계 보고서](./GAME_SYSTEM_DESIGN_REPORT.md)의 9·12–19·28절을 구체화한다. 스킬 수치·입력·이펙트뿐 아니라 **진화 조건·보상 보관·메서드 발동 조건**에 차이가 있으면 이 문서가 우선한다. 원본 HTML은 수정하지 않았다.  
> **결정 원칙:** 한 스킬을 고르면 피해량만 늘어나는 것이 아니라 목표 선택, 시전 위치, 후속 명령 중 하나가 달라져야 한다. 색은 식별의 보조 수단이며 모양·시간·소리로 같은 정보를 전달한다.

## 1. 이번 단계에서 확정하는 것

첫 제작 대상으로 액티브 6종(OVERCHARGE, VOID BOMB, BLACK HOLE, SCREEN CUT, ORBITAL COMMAND, LATENCY SEED), 각 2개 분기·2개 특수 변형·3단계 진화, 핵심 상태 8종, 빌드 메서드 12종, 첫 하이브리드 10종을 정한다. 기능 후보를 나열하지 않고 아래 효과를 **정식 효과**로 채택한다. 숫자는 플레이테스트 전 시작값으로, 발동 조건·입력·상한·상태 표식은 구현 계약이다.

## 2. 모든 효과가 공유할 전투 기준

### 피해 척도와 계산

초기 보통 적 **Drifter HP=100**을 기준 단위로 쓴다. 아래 숫자는 공격력 계수 `P=1.00`일 때의 실제 기본 피해다. 게임이 성장하면 `P`와 해당 출처의 보너스를 계산하되, **스킬 피해 보너스는 최종 피해 계산에서 정확히 한 번** 적용한다. 원본처럼 발사체 생성 때와 명중 때 중복 곱하지 않는다. 기본 피해 계산 순서는 `기본값 × P × (1+출처 보너스 합) × 대상 취약/저항 × 치명타`다. 같은 범주의 보너스는 더하고, 범주 사이만 곱한다. 최종 피해는 최소 1.

| 기본 동작 | 확정 초기값 | 의도 |
|---|---|---|
| 커서 자동 펄스 | 반경 110px 내 가장 가까운 적 1명에게 0.9초마다 피해 35. 적이 없으면 발사하지 않음. | 시작부터 잔몹 노동 감소. 직접 삭제/스킬 발동 효과는 일으키지 않음. |
| 직접 삭제 탭 | 충전 1개, 주대상 피해 110. 반경 36px의 다른 적 최대 3명에게 피해 40. 충전 최대 2, 충전당 2.8초 회복. | 고가치 목표 지정과 연쇄 시동. |
| 직접 삭제 홀드 | 0.8초 이상, 최대 1.2초. 충전 1개, 주대상 165, 반경 48px의 다른 적 최대 4명에게 55. | 늦게 누르는 대가로 단일·우선 목표 처리 강화. 반경만 무작정 키우지 않음. |
| 기본 치명타 | 직접 삭제의 주대상에만 5% 확률로 ×1.5. 확률 상한 60%. | IMPACT 빌드의 기초, 다른 스킬 자동 치명타 없음. |
| 일반 쿨다운 | 각 스킬의 아래 기본값에 쿨다운 감소 적용. 감소율 상한 40%. | 시전 빈도가 무한히 올라가는 조합 방지. |

스킬은 **장착한 E 또는 Q 버튼**을 기본으로 커서 위치에 즉시 시전한다. 슬롯을 바꾸면 스킬에 적힌 추가 입력도 함께 바뀐다. **OVERCHARGE**는 다음 직접 삭제를 무장하고 **SCREEN CUT**은 키 홀드로 방향을 지정한다. **Final VOID BOMB**은 누른 뒤 놓을 때 일반 배치/RECORD를 판정하므로 누르는 순간 폭탄을 놓지 않는다. 폭탄 배치·홀 배치·포격 지정·감염 심기는 직접 삭제 충전을 소비하지 않는다. 게임이 일시정지/선택 화면으로 넘어갈 때 무장·조준·RECORD 미리보기는 취소하되 쿨다운을 새로 부과하지 않는다. 쿨다운은 실제 시전/방출이 확정될 때 시작한다. 키보드·마우스 외 입력에서도 같은 행동 수가 되도록 게임패드는 조준 스틱+스킬 버튼을 쓴다.

직접 삭제 커서는 현재 충전 수를 2칸으로 보여준다. 탭 원은 실제 반경 36px, 누르는 동안에는 0.8초 임계까지 좁은 진행환이 차고 그 뒤 반경 48px 원으로 바뀐다. 1.2초 상한에서 진행환이 멈춘다. 충전 0개일 때는 공격 원이 점선으로 바뀌고 클릭해도 타격 이펙트가 나오지 않는다.

지속 상태가 생성된 뿌리를 `statusOwnerRoot`, 상태를 조기 종료시킨 타격의 뿌리를 `triggerRoot`로 따로 기록한다. 자연 만료는 둘 다 원래 뿌리다. 다른 직접 삭제가 감염을 기폭하면 틱·기폭의 피해 출처와 최초 호스트/기폭 4회/Final 1회 제한은 `statusOwnerRoot`를 따르고, 기폭에서 새로 생기는 전도·하이브리드는 `triggerRoot`의 후속 이벤트/예산을 쓴다. 두 뿌리 모두 §2 상한을 넘길 수 없고, 상태 인스턴스는 한 번 제거되면 다시 기폭되지 않는다.

**방패/보스:** 관통 비율은 합산해 최대 75%까지 피해를 본체에 먼저 배분한다. 남은 피해를 방패에 적용하고 방패 HP를 넘는 양은 본체로 넘긴다. NEEDLE 50%와 Precision Window 25%를 함께 쓰면 총 피해의 75%가 먼저 본체에 간다. 보스는 강제 이동 대신 BLACK HOLE 안에서 `Strain` 약점 누적을 받는다(§3). 전도·감염·폭발·소환 피해는 모두 보스에 적용하며, 다수 적을 전제로 한 전도의 **후속 타격만** 보스에 60% 계수를 적용한다. 보스가 한 명뿐이면 OVERCHARGE의 남은 전도 횟수는 아래의 단일 목표 보상으로 바뀐다.

### 효과 처리와 무한 루프 방지

직접 삭제·자동 펄스·액티브 시전은 새 `rootId`를 만든다. 그 결과 생긴 전도·감염 사망·폭발·하이브리드 파생 효과는 같은 `rootId`를 이어받는다. 한 뿌리당 후속 이벤트 최대 64, 추가 발동 예산 16, 세대 최대 5. 같은 `(rootId, effectId, targetId)` 조합은 **후속 효과 발동만** 한 번으로 제한한다. 다단 포격·홀 틱·잔상처럼 명시한 반복 **피해**는 별도 `hitIndex`로 모두 정산한다. 틱 피해는 매 틱 `onHit`를 다시 일으키지 않으며, 틱에서 적이 죽으면 `onKill`만 한 번 전달한다. 예산을 넘으면 **피해는 합산 정산하고 추가 발동만 생략**한다. 보스·Channeler·우선 목표 판정이 먼저 처리되며, HUD에는 통합된 연쇄 결과를 보여준다. 이 상한은 게임 규칙과 성능 규칙을 동시에 담당한다.

스카우트의 독립 자동 포격과 Final의 5초 자동 시동도 각각 새 뿌리다. 액티브 포격 4발과 홀의 모든 틱은 **한 시전 뿌리**를 공유한다. OVERCHARGE는 무장 때 피해 뿌리를 만들지 않고 실제 방출에 사용한 직접 삭제의 뿌리를 공유한다.

## 3. 핵심 상태 효과 사전

| 상태/고유 표식 | 판정·중첩·수명 | 플레이어가 확인할 정보 |
|---|---|---|
| **Conductive Mark** · 작은 지그재그 | 4초, 대상당 1개. 표식은 생성한 공격의 `originPosition`을 기록한다. 직접 삭제가 소비하면 가장 가까운 미타격 적 1명에게 60 전도. Evolution II부터 표식 처치도 1회 전도. 같은 뿌리에서 재부착 불가. | 표식 아이콘의 남은 시간선. 전도 가능 대상이 없으면 원대상에 피해 25를 되돌림. |

| **Rupture** · 흰 균열 한 줄 | 5초, 다음 직접 삭제 주대상 피해 +40% 후 소모. Exposed와 더해져 합계 취약 +70% 상한. | 소모 가능한 한 번의 약점으로 보임. |

| **Adaptive Fissure** · 분절 갑옷의 열린 출처 글리프 | 세계 적응 적의 대응과 동시에 부여. 대응 출처 피해는 최대 25% 경감, 표시된 대체 출처 피해 +30% 또는 보호선 차단. 약점 창 최소 4초. | 갑옷 틈 옆에 필요한 **공격 출처/행동 아이콘**(직접·폭발·다단·범위 밖 시전 등)을 표시. 공간 방향 약점일 때만 화살 사용. 완전 면역 없음. |

두 직접 피해 약점 `Exposed`/`Rupture`가 겹치면 +30%와 +40%를 **더해서** +70%로 적용한다. 감염·화상 틱은 치명타/직접 삭제 보너스를 받지 않는다. 상태의 피해값은 최초 적용 시점의 공격력을 저장하며 시간 갱신으로 숫자를 새로 크게 만들지 않는다. 재감염·재전도는 같은 뿌리에서 새 뿌리를 생성할 수 없다.

감염 대상에 직접 삭제와 조기 기폭 효과가 동시에 걸리면 **취약 상태 계산 → 직접 삭제 피해 → 감염 제거·기폭 1회** 순서다. 직접 피해로 적이 죽어도 사망 기폭과 수동 기폭을 두 번 만들지 않는다. `MANUAL DETONATE`, `Patient Zero`, `Patient Zero Strike`의 추가 피해는 같은 1회 기폭에 합치고, 추가 기폭을 만들지 않는다.

**CHAIN HEAT**는 적 상태가 아니라 플레이어의 연쇄 위험 게이지다. 한 `rootId`의 첫 전도 출발에 +16, 그 뿌리의 후속 전도 적중마다 +4. 마지막 전도 뒤 8초부터 초당 4 감소한다. 80 이상일 때 충전 직접 삭제를 쓰면 클릭 지점에서 반경 170px·피해 180의 **제어 붕괴**가 일어나고 게이지가 0이 된다. 제어 붕괴 처치 VOID +20%이지만 2초간 직접 삭제 충전 회복이 멈춘다. 100에 먼저 도달하면 마지막 전도 위치에서 자동 붕괴하며 VOID 보너스가 없다. 붕괴 파열은 추가 CHAIN HEAT를 만들지 않고 한 뿌리당 1회만 발동한다. HUD는 80 이상을 주황 빗금, 100 임박을 붉은 4칸으로 표시하고 붕괴 반경 170px을 직접 삭제 전에 커서에 예고한다.

## 4. 스킬 성장과 선택 시점

스킬 획득 후 **다음 일반 성장 선택 2회 안에 Branch A/B**를 제시한다. Branch 선택 뒤 다음 2회 안에 Special Modifier A/B를 제시한다. 두 번째 스킬을 늦게 얻어도 초반 절대 시간 때문에 분기를 잃지 않게 한다. 8·13·16분 진화 코어는 같은 스킬에 쓰면 순서대로 I→II→Final이 된다. 필요한 Branch/Modifier가 빠져 있으면 코어 선택 화면 직전에 해당 결정을 무료로 제공한 뒤 코어를 쓴다.

Final 조건은 해당 스킬 관련 태그 **4점 이상 + 그 스킬을 실제로 8회 유효 사용**이다. 유효 사용은 **한 시전당 최대 1회**이며, 적어도 한 대상에 피해·이동·상태 변화 중 하나가 실제 적용되었을 때만 센다. 포격 4발·홀 다단 틱·감염 틱을 각각 세지 않는다. 조건 충족 전의 코어는 버리지 않고 17:30까지 보관한다. 그때까지 미충족이면 다른 스킬의 가능한 진화 단계 또는 희귀 유물 1개 중 선택하게 한다. 어떤 경우에도 보상 소멸은 없다. 모든 최종 진화의 입력을 1회 연습할 수 있는 안전한 소규모 사건을 진화 뒤 30초 내 배치한다.

16분 코어에서는 **해당 스킬 Final** 또는 §11의 **태그 Final** 중 하나를 고를 수 있고, 한 런에서 Final은 최대 1개다. IMPACT/CASTER는 전용 액티브가 없어도 태그 Final로 완성할 수 있다. 전체 보고서 §12의 CHAIN `Closed Circuit`은 별도 카드가 아니라 OVERCHARGE `LIVING CIRCUIT`의 **회귀 경로 효과**를 가리킨다. INFECTION·SINGULARITY·SWARM은 각각 LATENCY SEED·BLACK HOLE·ORBITAL COMMAND Final로 완성된다.

## 5. OVERCHARGE — 경로를 고르는 전도

**역할:** 군집 시작점·방패 끝점 선택. **버튼:** E를 눌러 6초 무장 → 직접 삭제로 방출. 방출 시 직접 삭제 충전 1개와 스킬 쿨다운 10초를 사용한다. 만료되면 스킬은 5초만 재사용 대기한다. 무장 중 커서에는 최대 3갈래 *후보* 점선을 보여주되 적 이동에 따라 변할 수 있음을 점선으로 표현한다.

| 단계 | 확정 효과 |
|---|---|
| Base | 직접 삭제는 탭 110/홀드 165를 정상 적용한 뒤, 주대상에서 110px 이내의 **서로 다른** 적 최대 3명에게 순서대로 70/55/40. 전도 대상이 모자라면 남은 갈래당 주대상에 +15(최대 +45) 반환 피해. 반환은 추가 발동을 만들지 않음. |
| Branch A **FORK** | 갈래 +2. 후속 전도 값은 70/55/40/30/25의 각 70%; 최대 사거리 125px. 많은 약한 적에 유리. |
| Branch B **NEEDLE** | 후속 대상 최대 1명·피해 90. 첫 직접 삭제 피해의 50%를 Ward 본체에 우선 배분. 보스만 남았을 때의 반환 피해는 총 +60. 단일 보호자에 유리. |
| Special A **GROUNDING** | 후속 전도가 Ward 보호선 끝/Channeler에 닿으면 해당 보호·채널을 2초 중단. 같은 뿌리에서 한 번. |
| Special B **CAPACITOR** | 마지막으로 맞은 후속 대상 1명에 Conductive Mark. Evolution I 뒤에는 모든 생존 후속 대상에 표식; 표식 소비 전도 피해는 +20. |
| Evolution I **AMPLIFIED TRACE** | 모든 생존 후속 대상에 Conductive Mark 4초. 표시된 대상을 직접 삭제하면 미타격 적으로 전도 60. |
| Evolution II **RETURN CURRENT** | 표식 대상이 처치되면 적중한 뿌리당 최대 2회, 근처 미타격 적에 전도 55. 직접 삭제로 먼저 소비된 표식은 사망 재전도를 또 만들지 않음. |
| Final **LIVING CIRCUIT** | 방출 뒤 2.5초 `ROUTE` 창. 이때 E를 다시 누르면 커서 지점을 **한 번** 다음 출발 노드로 지정(직접 충전 미소모). 그 노드에서 유효 적에게 추가 전도: FORK는 최대 3명에 50/40/30, NEEDLE은 우선 목표 1명에 120. 대상이 없으면 원대상에 반환 피해 40. 지정하지 않으면 가장 가까운 미타격 적에서 약한 50 전도 1회. 지정 노드가 최초 출발점 40px 안으로 돌아오면 `Closed Circuit` 회귀가 완성돼 그 원 안 생존 적 최대 3명에 Exposed 3초. 전진 경로와 회귀 약점을 플레이어가 선택한다. 5초마다 나오는 자동 시동은 1명·피해 35로 제한. |

**이펙트 결정:** 무장 시 커서 옆 3갈래 각진 청록 점선, 커서 바깥에는 **6초 남은 시간을 줄어드는 원환**으로 보여준다. 방출 프레임에 굵은 첫 지그재그와 점차 얇은 후속선. 생존 표식은 적 둘레 작은 번개 흉터. Final의 수동 노드는 속 빈 큰 마름모와 **2.5초 원환**, 자동 시동은 속 찬 작은 마름모. 무장 만료·일시정지 취소 때는 후보선과 원환을 즉시 지운다. 소리는 무장 상승음 1회, 방출 강한 방전 1회, 후속선은 한 뿌리당 최대 2번 작은 클릭음. 봉합 저항을 만나면 선이 막힌 위치에 짧은 사각 절단 표식이 남고 필요한 공격 출처 글리프가 켜진다.

## 6. VOID BOMB — 시간을 예약하는 폭발

**역할:** 지정 위치·지연·기폭 판단. **버튼:** Final 전에는 스킬 버튼을 누른 **현재 커서 위치**에 즉시 배치한다. Final을 얻은 뒤에는 버튼을 눌렀다 **0.5초 미만에 놓으면** 일반 폭탄, 0.5초 이상 누르면 RECORD 미리보기로 전환하고 놓을 때 RECORD 폭탄을 확정한다. 최대 홀드 1.5초에 자동 확정하며 게임 시간은 계속 흐른다. 0.5초 임계 원환을 커서와 슬롯에 함께 표시한다. 기록 위치가 0개면 길게 눌러도 일반 폭탄만 배치한다. 직접 삭제 충전은 쓰지 않는다. 기본 쿨다운 12초는 배치 순간 시작한다. 폭발 예정 시간은 0.8초이며 적과 보스의 위험 예고보다 낮은 화면 우선순위에 놓는다.

| 단계 | 확정 효과 |
|---|---|
| Base | 반경 85px, 0.8초 뒤 피해 230. 바깥 20% 띠는 피해 60%. 적중한 한 대상에게 폭발당 한 번만 피해. |
| Branch A **CLUSTER** | 본 폭발 피해 170. 0.25초 뒤 살아 있는 서로 다른 대상 2곳에 반경 38px·피해 90의 작은 폭탄. 유효 대상이 하나뿐이면 작은 폭탄은 하나만. |
| Branch B **COMPRESSION** | 반경 55px, 중심부 피해 340. 바깥 띠 피해 60% 규칙 유지. |
| Special A **REMOTE FUSE** | 대기 중 폭탄 원 안에 직접 삭제를 쓰면 **현재 예정 시각과 입력 후 0.15초 중 빠른 시각**에 기폭. 조기 기폭 피해 −15%지만 직접 삭제가 부여한 상태는 먼저 적용됨. 한 폭탄의 퓨즈 예약은 1회만 변경. |
| Special B **DELAYED RETURN** | 본 폭발 뒤 3초 잔류 원(반경의 70%)이 남아 초당 피해 30. 잔류 틱은 후속 발동을 일으키지 않음. |
| Evolution I **SHOCK RING** | 폭발 생존자들을 중심에서 바깥으로 최대 90px 밀고 Exposed 3초 부여. 보스는 이동하지 않고 Exposed만 받음. |
| Evolution II **CHAIN REACTION** | 한 번의 폭발에서 5명 이상 처치하면 가장 먼 생존 적 1곳에 0.5초 뒤 반경 45px·피해 80의 미니 폭탄. 한 시전당 1개. 보스 단독 적중이면 대신 Rupture 2초. |
| Final **TOTAL VOID** | 버튼을 0.5초 이상 누르면 `RECORD` 모드로 전환. 최근 10초의 직접 삭제 **적중 위치** 최대 5곳을 미리 보여주고, 버튼을 놓은 커서 지점에 폭탄을 배치한다. **배치 0.8초 뒤** 반경 110px·피해 180의 본 폭발, 이후 기록 지점마다 **0.12초 간격**으로 반경 30px·피해 70의 유령 폭발을 순서대로 재생. 기록이 0개면 일반 폭탄만 사용 가능. RECORD 쿨다운 24초, 일반 폭탄은 여전히 12초. 유령 폭발은 새 기록/유령 폭발을 만들지 않음. |

RECORD에서는 선택한 Branch를 유령 폭발 쪽에 적용한다. CLUSTER는 기록 최대 7곳·유령 피해 50/반경 30px, COMPRESSION은 최대 5곳·유령 피해 100/반경 22px. 본 폭발은 어느 Branch에서도 Final 고정 수치 180/110px이다. REMOTE FUSE는 RECORD의 0.8초 대기 중 직접 삭제를 맞히면 **현재 예정 시각과 입력 후 0.15초 중 빠른 시각**에 본 폭발을 일으키고 본 폭발 피해만 −15%로 바꾸며 유령 간격/피해는 유지한다. DELAYED RETURN·SHOCK RING·CHAIN REACTION은 RECORD 본 폭발에만 적용되고 유령 폭발로 중복 생성되지 않는다.

**이펙트 결정:** 배치점에 **실제 본 폭발 반경**의 8분할 시계환이 0.8초간 닫히고, 마지막 0.15초에 환이 얇아진다. 폭발은 화면 전체 섬광 대신 원 내부를 0.08초 비우고 테두리를 한 번 바깥으로 보낸다. CLUSTER는 작은 별도 시계환 2개, COMPRESSION은 촘촘한 작은 환. RECORD는 본 폭발의 **반경 110px 시계환**과 선택 Branch에 맞는 **반경 30/22px 유령 발자국**을 함께 보여준다. 유령 발자국은 본 폭발 예정 시각부터 0.12초씩 늦게 닫히는 번호/얇은 선으로 순서를 읽게 한다. 소리는 퓨즈 2틱과 낮은 충격 1회; 유령 폭발은 연속 폭음 대신 마지막 한 번만 강조한다.

## 7. BLACK HOLE — 적의 위치를 자원으로 바꾸기

**역할:** 군집 압축·보호망 분리. **버튼:** E를 누른 커서 위치에 즉시 설치, 기본 쿨다운 16초. 반경 125px, 유지 3초. 일반 적을 최대 초당 140px로 중심에 끌고, 내부 적에게 0.5초마다 피해 15, 종료 시 반경 80px 피해 80. 보스는 당겨지지 않지만 틱·종료 피해는 받는다.

| 단계 | 확정 효과 |
|---|---|
| Branch A **TWIN** | 85px 반경 두 중심을 커서 좌우 70px에 생성. 각 홀의 흡입·틱·종료 피해 70%. 두 중심 사이의 적은 더 가까운 한쪽만 영향. |
| Branch B **ANCHOR** | 단일 중심 반경 145px. 흡입 최대 속도 130px/s, 내부 피해·종료 피해 동일. 고정점 앞 방어에 유리. |
| Special A **MASS LEDGER** | 기본 Mass의 종료 피해를 +20/눈금에서 +30/눈금으로 바꾸고 최대 추가 피해를 +240으로 높임. 축적 조건과 최대 8눈금은 그대로. |
| Special B **TIDAL PULL** | 빠른 적이 홀 경계를 벗어날 때 1.5초 이동 속도 −25%. 보스에는 이동 대신 Exposed 2초. |
| Evolution I **GRAVITY CRUSH** | 종료 0.35초 전에 **실제 종료 피해 반경 80px** 원을 예고. 종료 피해와 Mass를 적용하며 반경 내 Ward 보호 연결 1개를 끊음. |
| Evolution II **REPOSITION** | 설치 뒤 3초 안에 스킬 버튼을 다시 누르면 커서 위치로 중심을 **한 번** 최대 180px 이동. TWIN은 두 중심의 중점을 이동. 기존 쿨다운은 재시작하지 않음. Final 단계에서는 첫 1.2초는 REALITY FOLD의 B 지정이 우선하고, 1.2초 이후에만 이 재배치를 쓸 수 있음. |
| Final **REALITY FOLD** | 첫 스킬 버튼으로 중심 A를 놓고, **1.2초 안의 두 번째 입력**으로 중심 B(거리 80–360px)를 정한다. B는 접힘의 **고정점**이며 추가 흡입·틱을 만들지 않는다. TWIN의 A는 두 홀 중점이고 접힘 계산용 Mass는 두 홀 합산 최대 8. 두 번째 입력 전에는 A의 기존 홀이 정상적으로 흡입한다. 두 중심 사이에 **폭 32px의 실제 피해 통로**를 0.6초 예고한 뒤 피해 200 + 저장 Mass×20을 1회 주고 보호선을 끊는다. B가 거리 밖이면 입력을 소비하지 않고 유효 거리 환을 표시한다. 1.2초 안에 B를 정하지 않으면 접힘은 포기하고, 1.2–3초에는 REPOSITION만 가능하다. HUD는 이 두 창을 다른 아이콘과 남은 시간으로 표시. |

**이펙트 결정:** 보라색 동심원 2–3개가 안쪽으로 수축하고 네 방향 유입 화살이 속도를 설명한다. 중심의 8칸 Mass 눈금은 처치 때만 한 칸씩 채운다. 종료 0.35초 전 **피해 반경 80px 원**이 흰 선으로 바뀌고, 종료 충격은 바깥으로 단 한 번. TWIN은 연결된 두 중심, REPOSITION은 이전 중심에서 새 위치로 짧은 궤적, REALITY FOLD는 0.6초 동안 **폭 32px 피해 통로의 양쪽 경계선**을 먼저 표시한다. 지속 저음은 매우 작게, 눈금 단계와 종료 타격음만 명확하게 둔다.

## 8. SCREEN CUT — 선과 교점으로 전장을 나누기

**역할:** 보호 연결 절단, 흩어진 목표를 한 줄로 처리. **버튼:** 스킬 버튼을 누르는 동안 커서를 움직여 방향을 그리며, 놓을 때 절단한다. 누름 0.2초 미만의 탭은 마지막 사용 방향(첫 사용은 수평)으로 즉시 절단한다. 조준은 최대 1.2초, 그 뒤에는 자동 방출한다. 조준 중 게임 시간은 흐른다. 직접 삭제 충전은 쓰지 않고 방출 순간 쿨다운 11초 시작. 기본 절단선은 커서 중심 길이 400px·폭 26px·피해 200, 대상당 한 번.

| 단계 | 확정 효과 |
|---|---|
| Branch A **LATTICE** | 주 절단선과 수직선 2개, 각 피해 130. 교점에 걸린 한 대상은 총 피해 최대 220. 군집·보호 연결에 유리. |
| Branch B **RAZOR** | 길이 460px·폭 12px·피해 285. 한 줄의 고가치 적/보스에 유리. |
| Special A **AFTERIMAGE** | 0.5초 뒤 같은 선을 피해 70으로 다시 긋는다. 이전에 이미 맞았던 적도 재적중 가능하지만 각 선당 1회만. |
| Special B **RUPTURE EDGE** | 첫 절단 적중 생존자에 Rupture 5초. 다음 직접 삭제의 주대상을 고르게 함. |
| Evolution I **LINGERING SEAM** | 선 위치에 2초간 점선 균열. 적이 선을 처음 통과할 때 Exposed 2초를 받음. 추가 통과는 시간만 갱신. |
| Evolution II **RIFT CROSSING** | LATTICE는 주선과 두 수직선의 교점 최대 2곳을 쓴다. RAZOR는 매 시전 주선 중앙에 길이 90px·폭 10px의 **피해 없는 수직 보조 균열**을 0.25초 뒤 1초간 만들고 그 교점 1곳을 쓴다. 각 유효 교점에 반경 45px·피해 100 파열. AFTERIMAGE의 같은 선 중첩은 새 교점이 아니며, Special 어느 쪽이든 발동한다. 한 시전당 최대 2교점; 같은 교점 중복 없음. |

**이펙트 결정:** 조준 선은 얇은 흰 점선과 방향 화살. 적중 프레임에 고대비 단일 직선, 잔광은 0.25초 미만. LATTICE는 수직 가이드, RAZOR는 좁고 길게. `LINGERING SEAM`은 반투명 불투명 면이 아닌 가는 점선, 교점 파열은 작은 X 한 개. LAST JUDGEMENT는 이동 가능한 기점을 속 빈 다이아로, 다음 0.4초 판정 부채꼴을 점선으로 보여준다. 저동작 모드에서는 회전 잔상 대신 현재선과 다음 판정 부채꼴을 정지 단계로 갱신한다. 소리는 짧은 절단음 1회, 교차 때만 별도 탁음. 여러 절단음이 겹치면 같은 뿌리에서 첫 음과 마지막 음만 남긴다.

## 9. ORBITAL COMMAND — 자동망을 지휘하는 포격

**역할:** 소환체의 자동 처리와 플레이어의 표적 명령을 분리한다. **보유 패시브:** 스카우트 레플리카 1기가 커서 110px 안의 가장 가까운 적에게 2.1초마다 피해 25를 준다. 패시브는 적 처치 VOID를 정상 지급하지만 직접 삭제/스킬 사용 효과는 발동하지 않는다. **액티브:** 버튼을 누른 커서에 반경 90px의 5초 명령 구역을 놓고 레플리카 2기가 0.6/1.7/2.8/3.9초에 교대로 **총 4발**, 한 발당 반경 44px·피해 55를 포격한다. 쿨다운 14초는 명령 순간 시작. 구역 안에서 Channeler/우선 목표 > 보호자 > HP 높은 적 순으로 찾는다.

| 단계 | 확정 효과 |
|---|---|
| Branch A **WATCHTOWER** | 명령 구역이 가장 가까운 현실 고정점에 붙어 5초 방어. 그 고정점을 채널링 중인 적이 있으면 무조건 우선 표적. 피해 수치는 동일. |
| Branch B **HUNTER** | 명령 구역이 선택한 우선 목표/엘리트를 따라간다. 착탄 예고가 0.15초 더 길어 도망가는 적을 조준할 수 있지만 밀집군 전체의 방어는 약해짐. |
| Special A **MARKED TARGET** | 명령 구역 안의 적을 직접 삭제로 적중시키면 다음 한 발의 탄착점을 그 위치로 고정하고 피해 +30. **현재 탄의 착탄 0.3초 잠금 전**이면 현재 탄에, 잠금 뒤이면 다음 탄에 예약한다. 남은 미잠금 포격이 없으면 예약/횟수 소모 없음. 명령당 최대 2회. |
| Special B **INCENDIARY FUEL** | 포격 한 발이 적중한 자리 반경 35px에 **2.4초 바닥 화염 구역**을 놓음. 구역 진입 적은 구역당 1회 Burn 2.4초를 받으며 Burn의 남은 시간은 진입 순간부터 계산. 화염은 전도/감염 출발점이 되지 않음. |
| Evolution I **TARGET LOCK** | 기본 포격은 예고 시작 때 고른 위치를 쓰고 MARKED TARGET/구역 재지정만 잠금 전에 반영한다. 이 진화부터는 **적 이동도** 착탄 0.3초 전까지 추적 갱신한다. 마지막 0.3초는 어떤 명령에도 고정하며 변경 목표는 HUD 괄호로 표시. |
| Evolution II **FIELD COMMAND** | 명령이 지속되는 동안 버튼을 다시 누르면 구역을 커서 위치로 **한 번** 재지정. 새 쿨다운 없음. 재지정 시 다음 탄착 예정 시각은 유지하고, 이미 0.3초 실선으로 잠긴 탄은 이전 위치에 떨어진다. |
| Final **CROSS NETWORK** | 획득 즉시 `NETWORK` 게이지 **50**과 T 스킬을 받는다. 이후 액티브 **포격 한 발이 한 명 이상 적중하면 +2**(여러 명 적중해도 +2), 명령 구역 안 목표를 직접 삭제 처치하면 목표당 +5, 최대 100. 50 이상에서 T를 누르면 현재 커서를 따라 움직이는 수평/수직선이 5초 유지(쿨다운 18초, 게이지 전량 소모). 각 선의 **실제 판정 폭은 24px**이고, 적 원과 선이 겹치면 0.2초마다 피해 14, 적 원이 두 선 모두와 겹치면 그 틱의 **총 피해 30**; 대상당 매 틱 1회. 100 게이지는 교차점에 Exposed 2초를 부여하는 `Perfect`이며 추가 피해 배수는 없음. |

**이펙트 결정:** 패시브 스카우트는 작은 사각 프레임 하나, 액티브 명령은 직각 괄호가 있는 조준 원. 각 탄착에는 **실제 반경 44px 원**을 예고한다. 기본은 착탄 0.35초 전부터 0.3초 전까지 움직이는 점선, 마지막 0.3초는 고정 실선이다. HUNTER는 0.5초 전에 점선을 시작해 예고를 0.15초 늘리고 동일한 마지막 0.3초 실선 고정을 지킨다. 포격의 먼지는 짧고 불투명하지 않다. WATCHTOWER는 고정점 테두리, HUNTER는 이동 표적 괄호로 구분한다. 바닥 화염 구역은 점선 원, 적에게 붙은 Burn은 작은 불꽃으로 그린다. CROSS NETWORK는 네 포탑 실루엣과 두 **폭 24px 판정 영역을 보여주는 경계선**, 밝은 마름모 교차점으로 표현한다. 100 게이지에서도 전체 화면 번쩍임은 없다. 소리는 표적 확보 비프 1회, 첫·마지막 탄착만 큰 중저음; 네 발마다 큰 폭음이 나지 않게 한다.

**출처 계약:** 패시브/포격 피해는 `SUMMON`, CROSS NETWORK는 `SKILL`. `skillDamage`를 포격에 중복 적용하지 않고 `summonDamage`는 스카우트/포격에 한 번만, CROSS에는 `skillDamage`를 한 번만 적용한다. 원본에서 자동 포격과 E/Q 사용이 서로 다른 흐름이던 점은 유지하되, 초기 액티브가 안내 문구뿐인 상태는 없앤다.

## 10. LATENCY SEED — 기다림과 조기 기폭의 선택

**역할:** 시간차 위험·공간 선점. **버튼:** 누른 커서에서 45px 안의 가장 가까운 적 1명에 심는다. 없으면 반경 45px의 바닥 씨앗을 5초 설치해 첫 통과 적에게 심는다. 쿨다운 10초. 감염은 3초 동안 초당 피해 25, 1.5초 뒤 70px 이내 건강한 적 1명에게 1회 전파한다. 자식 감염은 기본 재전파하지 않는다. 사망 시 기폭 피해 110, 만료 시 기폭 피해 145(반경 65px). 한 뿌리의 첫 4회 기폭만 후속 발동을 만들고 **나머지 기폭 피해는 유지**한다.

| 단계 | 확정 효과 |
|---|---|
| Branch A **CARRIER** | 최초 호스트가 1.1초와 2.0초에 서로 다른 적 1명씩 전파(최대 2명). 자식의 틱·기폭 피해는 65%, 자식 재전파 없음. 군집의 시간차 처리. |
| Branch B **RESERVOIR** | 전파 없음. 최초 호스트 틱 피해 +10/초, 사망·만료 기폭 피해 +70. 우선 목표/보스에 집중. |
| Special A **MANUAL DETONATE** | 감염자를 직접 삭제로 적중시키면 남은 시간을 무시하고 즉시 기폭(기본 사망 기폭값 +20%). 직접 타격은 원래 피해를 정상 적용. |
| Special B **DORMANT SOIL** | 감염자가 처치된 위치에 3초간 반경 35px 잠복 지대. 첫 통과 적 1명에게 약한 감염(원래 틱/기폭의 65%)을 부여하고 사라짐. 한 뿌리당 지대 1개. |
| Evolution I **VIRAL TRACE** | 감염된 적이 움직인 경로에 최대 길이 90px, 2초짜리 가는 흔적. 흔적을 건너는 건강한 적 최대 2명에 약한 감염(65%). 흔적은 중첩돼도 한 적에 1회. |
| Evolution II **HOST TRANSFER** | 최초 감염 호스트가 처치되면 근처 건강한 적 1명으로 남은 감염을 옮김. 이식은 한 뿌리당 1회, 이식된 적은 다시 이식하지 않음. |
| Final **EPIDEMIC SCRIPT** | Final을 얻으면 Special 선택과 무관하게 감염자 직접 삭제 **적중**으로 감염을 즉시 기폭할 수 있다. MANUAL DETONATE가 있으면 그 기폭에 기존 +20%를 더하고, DORMANT SOIL은 처치 시에만 잠복 지대를 남긴다. 조기 기폭 뒤 **0.5초 방향 지정 창**이 열린다. 기폭 위치를 원점으로 반경 150px·개구각 90° 부채꼴을 **기폭 순간부터 커서가 움직인 방향**에 보여준다. 창 끝에 중심점이 부채꼴 안인 미감염 적 중 가까운 최대 3명에 약한 감염(65%)을 심는다. 커서 이동량 20px 미만이면 기폭 위치 150px 안의 가까운 두 적을 자동 선택. 동거리면 대상 ID 순. 한 `statusOwnerRoot`당 1회이며 자식은 다시 `EPIDEMIC SCRIPT`를 만들지 않음. |

**이펙트 결정:** 감염자는 적 가장자리에 3분할 원환. 1초가 지날 때마다 한 구획이 닫혀 기폭 시간을 읽는다. 전파는 호스트 사이 짧은 점선 궤적 한 번, 바닥 씨앗은 작은 점선 원. CARRIER는 이동 방향의 짧은 꼬리, RESERVOIR는 원환 안 눈금. 조기 기폭은 바깥 큰 초록 구름 대신 원환이 **안쪽으로** 접히며 작은 파열을 만든다. Final은 0.5초 동안 실제 수신 대상이 될 부채꼴과 진행환을 함께 보여준다. 소리는 심을 때 낮은 음 한 번, 마지막 박자 한 번, 기폭 시 짧은 팝; 전파마다 별도 효과음을 울리지 않는다.

## 11. 빌드 메서드 12종 — 액티브 밖에서 일어나는 효과

메서드는 일반 능력치 카드와 다른 **규칙 카드**다. 관련 태그 4점부터 후보에 나오며, 실제 발동 출처가 더 필요한 카드는 아래 선행 조건까지 만족해야 한다. 같은 이름의 스킬 분기·특수 변형·진화와 중복 카드를 만들지 않는다. 아래 12종을 첫 카드 풀의 기준으로 채택한다. `피해 N`은 §2의 P=1 기준이고, 메서드의 파생 피해는 자체 명시가 없는 한 치명타를 굴리지 않는다.

| IMPACT · **Precision Window** | Exposed/Rupture 대상에 홀드 직접 삭제를 넣으면 주대상 피해 +60, 그 직접 피해의 25%를 방패보다 본체에 우선 배분. | 내부 쿨다운 6초. 홀드 원에 세로 홈 1개. |
| CASTER · **After Cast** | 액티브 스킬 확정 **후** 2초 안의 첫 별도 직접 삭제 주대상 피해 +30% 및 생존자 Exposed 2초. OVERCHARGE 방출에 쓰인 직접 삭제는 자기 자신이 만든 After Cast를 받지 않고 그 **다음** 직접 삭제가 받음. | 시전당 1회. E/Q 아이콘에서 커서로 짧은 연결선. |
| CASTER · **Alternating Circuit** | 서로 다른 두 스킬을 5초 안에 차례로 시전하면 **첫 스킬**의 남은 쿨다운을 기본 쿨다운의 20%만큼 줄임. | 각 스킬의 자연 쿨다운 주기당 1회, 남은 쿨다운 최소 2초. 환급이 새 시전/후속 발동을 만들지 않음. 두 글리프가 맞물림. |

**출현 선행 조건:** Conductive Scar·Overkill은 기본 직접 삭제만으로 발동한다. Origin Echo는 Conductive Mark 생성 출처, Spore Census·Patient Zero는 감염 출처가 필요하다. Spore Census는 기본 LATENCY SEED의 호스트+전파 자식 **2명**만으로도 조건을 채울 수 있다. Orbit Shear·Event Horizon은 BLACK HOLE이 필요하며 Event Horizon의 Mass 6은 일반 적 6명 또는 엘리트 2명 처치 등 **6눈금**을 뜻한다. Target Lease·Relay Beacon은 ORBITAL COMMAND가 필요하고 Relay Beacon은 특히 **액티브 명령 구역**을 생성할 수 있어야 한다. Precision Window는 Exposed/Rupture 생성 출처, After Cast는 액티브 1개, Alternating Circuit은 서로 다른 액티브 2개가 필요하다. 조건이 사라지는 슬롯 교체 시 해당 메서드는 카드 보유 상태를 유지하되 회색 잠금으로 표시하고 출처를 되찾으면 재활성화한다.

메서드 출현 검사는 `prerequisites`와 실제 이벤트 처리기를 함께 확인한다. 원본에서 카드 설명만 있고 효과가 없거나 후보 풀에 들어갈 수 없던 상태를 반복하지 않도록, 플레이 가능한 빌드 카드에는 `effectId`와 실제 트리거가 반드시 있어야 한다.

### IMPACT·CASTER 태그 Final

16분 코어의 **스킬 Final 대안**이다. 각 태그 4점과 아래의 실제 행동 8회가 필요하며, 조건을 채웠을 때만 Final 선택 화면에 나온다. 이미 스킬 Final을 얻었다면 고를 수 없다. 획득 직후 30초 안에 각각 생존 엘리트와 E→Q를 실행할 두 목표가 나오는 연습 사건을 배치한다. 두 Final은 액티브 슬롯을 차지하지 않는다.

| 태그 Final/진입 조건 | 확정 효과 | 이펙트·피드백 |
|---|---|---|
| IMPACT **FINAL STROKE** · 0.8초 이상 충전한 직접 삭제 주대상 유효 적중 8회 | **1.2초 완충 직접 삭제**가 주대상을 맞히면, 살아남은 주대상에 4초 `Stroke Scar`를 남긴다. 주대상이 죽었으면 클릭 지점 110px 내 가장 가까운 우선 목표/생존 적 1명에 남긴다. 다음 `SKILL` 또는 `SUMMON` **직접 적중** 1회가 흉터를 소비해 해당 피해 +35%와 Ward 보호 연결 1개 절단. 틱 피해는 소비하지 않는다. 내부 쿨다운 6초, 대상당 흉터 1개. | 완충 원환 마지막 0.4초에 주황 세로 홈이 채워진다. 타격 뒤 적에 짧은 쐐기 흉터, 다음 출처 적중 때 흰 절단선 1개. | CASTER **REWRITE SEQUENCE** · 서로 다른 E→Q 액티브를 5초 안에 유효 시전한 쌍 8회 | E 유효 시전→5초 내 Q 유효 시전→**첫 E로부터 5초 안의** 별도 직접 삭제 적중을 완성하면, Q 스킬의 주 태그에 따른 아래 일회성 효과를 클릭 목표에 적용한다. 목표가 죽었으면 110px 내 가장 가까운 생존 적을 쓴다. 효과는 직접 삭제의 `rootId`를 이어받으며 한 쌍당 1회, 내부 쿨다운 12초. | E/Q 두 글리프가 순서대로 켜지고, Q 뒤 커서에 **첫 E부터 계산한 남은 시간**과 Q 태그 아이콘을 보여준다. 완성 순간 해당 태그의 작은 말단 표식을 붙인다. 실패/만료는 글리프가 조용히 꺼진다. |

`REWRITE SEQUENCE`의 Q 주 태그는 고정이다: OVERCHARGE=CHAIN, VOID BOMB=IMPACT, BLACK HOLE=SINGULARITY, SCREEN CUT=CASTER, ORBITAL COMMAND=SWARM, LATENCY SEED=INFECTION. CHAIN은 Conductive Mark 4초, IMPACT는 Rupture 5초, SINGULARITY는 반경 80px 일반 적을 중심 쪽 60px 당기고 보스에는 Strain +1, CASTER는 Exposed 3초, SWARM은 0.3초 뒤 해당 대상에 반경 44px·피해 35의 스카우트 1발, INFECTION은 틱·기폭 피해 65%의 약한 감염 1회다. 이 효과는 각 상태의 기존 중첩·뿌리 상한을 따른다. 별도 출처가 필요한 피해는 `SKILL`/`SUMMON`으로 정확히 한 번 계산한다.

REWRITE의 SINGULARITY는 선택 대상 중심 **반경 80px 실제 당김 원**을 0.15초 보이고 적용한다. SWARM은 대상 위치에 **반경 44px 고정 착탄 원과 0.3초 진행환**을 그린 뒤 포격한다. 나머지 네 결과는 대상에 실제 상태 글리프를 즉시 붙인다. 이 예고도 적/보스 위험 예고보다 아래 레이어에 둔다.

## 12. 첫 제작 Cross-Build 10종의 발동 계약

두 태그가 각각 4점 이상이고 하이브리드 카드 1장을 **실제로 획득**해야 발동한다. 하이브리드 슬롯은 1개다. 아래 순서는 [전체 보고서](./GAME_SYSTEM_DESIGN_REPORT.md)의 첫 제작 10종과 같다. 하이브리드는 새 대형 광역 이펙트를 추가하기보다 주 효과 모양에 보조 태그의 말단 표식 1개를 붙인다.

| 조합/이름 | 정확한 작동 | 제한·시각 신호 |
|---|---|---|
| CHAIN+INFECTION **Contagion Circuit** | 전도가 감염자를 적중하면 다음 전도 대상에 남은 감염 시간의 65%를 복사. 그 전도의 피해는 정상. | 뿌리당 2회, 복사된 감염은 재복사 불가. 청록 지그재그 끝에 3분할 원환. |
| CHAIN+SINGULARITY **Orbit Relay** | 전도선이 홀 안의 적을 적중하면 Mass 2를 소모하고 홀 반대편에서 가장 가까운 미타격 적 1명에 피해 55로 재출발. | 뿌리당 1회. 선이 홀 안에서 끊겼다가 반대 외곽에서 나옴. |
| CHAIN+SWARM **Relay Hunt** | 액티브 포격의 명령 구역 안 적을 직접 삭제 처치하면 명령 구역 중심에서 미타격 적 2명에 피해 55 전도. Target Lease/비컨이 있다면 그 위치를 출발점으로 우선 사용. | ORBITAL COMMAND 보유 때만 카드 후보. 내부 쿨다운 4초, 뿌리당 1회. 사각 비컨에서 각진 두 선. |
| CHAIN+IMPACT **Railgun Scar** | 홀드 직접 삭제가 치명타이거나 주대상 초과 피해 50 이상이면 최근 0.25초 커서 이동 방향으로 길이 360px·폭 14px 관통선 피해 100. 이동량 20px 미만이면 수평 방향. | 뿌리당 1회, 같은 대상 추가 적중 1회만. 쐐기 뒤 청록 일직선. |
| CHAIN+CASTER **Echo Order** | E 슬롯 스킬→Q 슬롯 스킬을 5초 안에 사용했다면 Q의 첫 적중 대상에서 0.4초 뒤 미타격 적 1명으로 피해 50의 전도를 새로 만듦. Q 자체가 전도 스킬일 필요는 없음. | 스킬 순서당 1회. 두 글리프 뒤 짧은 흰-청록 반향. |
| INFECTION+SINGULARITY **Quarantine Collapse** | 홀 안 감염자는 홀 밖으로 전파하지 않고 전파 기회를 저장. 홀 종료 때 외곽 미감염 적 최대 3명에 약한 감염(65%)을 동시에 방출하며 홀 종료 피해 +40. | 홀당 1회, 새 자식은 전파 불가. 보라 원 안의 초록 점 3개가 외곽으로 이동. |
| INFECTION+SWARM **Parasite Hive** | 액티브 포격이 명중한 첫 생존 적에게 약한 감염(65%) 부여. 명령 구역 안에 감염자가 있으면 스카우트가 그 호스트 주변 미감염 적을 우선 공격. | 포격 명령당 감염 최대 2명. 사각 조준점 안에 원환 1개. |
| INFECTION+IMPACT **Patient Zero Strike** | 홀드 직접 삭제가 감염자에 적중하면 감염을 즉시 기폭하고 남은 감염 시간 1초당 피해 +30(최대 +90). | 뿌리당 1회. 쐐기가 3분할 원환을 안으로 깨뜨림. |
| INFECTION+CASTER **Delayed Script** | 첫 스킬이 심은 감염을 **다른 슬롯 스킬**이 5초 안에 기폭하면 두 번째 스킬의 남은 쿨다운을 2초 줄임. | 두 번째 스킬의 쿨다운 주기당 1회, 최소 잔여 2초. 두 글리프 사이 점선 원환. |
| SINGULARITY+SWARM **Cross Gravity** | 액티브 포격 명령 구역과 블랙홀이 동시에 있으면 명령 구역 중심이 홀을 초당 최대 80px 끌어온다. Final CROSS NETWORK 사용 중에는 교차점이 대신 초당 최대 120px로 이동시킨다. 피해·Mass는 그대로이고 자동 이동 중 수동 홀 재배치는 잠김. | BLACK HOLE과 ORBITAL COMMAND 보유 때만 카드 후보. 한 홀만 연결, 가장 가까운 홀 우선. 직각 축/명령 괄호에서 보라 중심으로 얇은 유도선. |

**발동 순서 예:** `DIRECT 처치 → Conductive Scar 표식 → Contagion Circuit 복사 → Infected 틱/기폭 → onKill`처럼 추적한다. 동일 뿌리에서 `onKill`이 다시 전도를 불러도 §2 상한을 그대로 지킨다. 하이브리드의 목적은 처리량의 무한 증가가 아니라 *다른 위치·순서·표적을 선택할 이유*를 만드는 것이다.

후보 검사는 태그 점수에 더해 **실제 발동 출처 보유**를 요구한다. Orbit Relay/Quarantine Collapse/Cross Gravity는 BLACK HOLE, Relay Hunt/Parasite Hive/Cross Gravity는 **액티브 명령 구역을 만드는 ORBITAL COMMAND**, Contagion Circuit/Orbit Relay는 실제 전도 출처, Contagion Circuit/Quarantine Collapse/Patient Zero Strike/Delayed Script는 감염 출처, Echo Order/Delayed Script는 서로 다른 두 스킬 슬롯이 필요하다. 조건이 없으면 획득 불가 카드로 표시하지 않고 도감에서 필요 조건을 보여준다.

## 13. 전투 이펙트의 공통 시각 언어

화면 바탕은 짙은 남흑색 `#050711`을 기준으로 한다. 밝은 색이 많아지는 후반에도 적의 윤곽과 위협 예고가 살아야 하므로 효과는 *넓게 칠하는 면*보다 선·테두리·짧은 잔상으로 만든다. 색각 설정과 상관없이 아래 **형태가 먼저 식별자**다.

| 출처/상태 | 보조 색 | 고유 형태와 움직임 | 기본 소리 |
|---|---|---|---|
| CHAIN | 청록 `#5EE3FF` | 각진 지그재그·갈라지는 끝점 | 짧은 고음 클릭, 갈래마다 음량 감소 |
| INFECTION | 연두 `#A6E857` | 3분할 원환·점선 포자 경로 | 낮은 3박 맥동, 마지막 박자 강조 |
| SINGULARITY | 보라 `#A67CFF` | 수축 동심원·안쪽 화살 | 매우 낮은 흡입음, 종료 한 번 강조 |
| SWARM | 황금 `#F2C15A` | 직각 괄호·사각 비컨·십자 탄착점 | 표적 확보 비프, 짧은 금속 타격 |
| IMPACT | 주황 `#FF8C6B` | 쐐기·짧은 방사형 균열 | 건조한 단발 타격음 |
| CASTER/절단 | 백금 `#E8F0FF` | E/Q 두 글리프·얇은 직선·교차 X | 서로 다른 두 음의 응답 |
| VOID BOMB | 분홍 `#ED78BF` | 8분할 시계환·안쪽 공백 | 퓨즈 2틱과 둔탁한 한 번의 충격 |
| **위험 예고** | 적색 `#FF425B` | **빗금 테두리+안쪽 방향 화살** | 가장 우선되는 1회 경고음 |

한 개체에 붙는 상태 그림은 **주 상태 1개+보조 글리프 2개**까지다. 우선순위는 고정점 채널/보스 약점 > Adaptive Fissure > Infected/Conductive Mark > Exposed/Rupture/Strain > Burn. 숨겨진 상태는 해당 적의 정보 툴팁에서는 모두 볼 수 있다. 보스·Channeler·우선 목표는 상태 압축 예외로, 위협/약점 아이콘을 항상 보여준다. 일반 적이 80명 이상 보이면 커서 반경 160px 밖의 같은 상태 적은 **군집 대표 1개+개체 수**로 묶고, 개별 타이머는 커서 근처/우선 목표/보스에만 남긴다. 위험 예고와 실제 타격 원은 군집 압축에서도 개별 판정을 그대로 그린다. 하이브리드는 주 출처 형태에 보조 태그의 작은 말단 글리프만 덧붙인다. 두 색을 섞어 정체불명의 새 폭발을 만들지 않는다.

**공통 타이밍:** 단순 스킬의 입력→반응은 0.1초 이내, 지연 공격은 공격 범위와 남은 시간을 시작부터 표시한다. 강한 공격의 명중 강조는 0.08–0.12초, 잔광은 0.25초 이내. 화면 전체 흰 섬광은 사용하지 않는다. 카메라 흔들림은 보스 큰 타격에만 최대 3px/0.1초, 일반 연쇄에는 없다. 첫 발동 이름 팝업은 0.8초 뒤 자동 축소되고 전투 텍스트를 가리지 않는다.

### 합성/렌더 우선순위

1. **항상 최상단:** 고정점 채널 경고, 보스 공격 예고·약점, 플레이어 입력 목표/커서. 적 위협 예고는 최소 1초, Channeler 채널은 2초. 피해 판정 영역과 그려진 예고 영역은 일치해야 한다.
2. **그 아래:** 직접 삭제·스킬의 첫 원인, 착탄 위치, 중요한 상태 변화. 전도 20갈래가 있어도 첫 3경로와 전체 처치 결과만 강조한다.
3. **배경:** 반복 포격·감염 틱·Burn·장식 파티클. 위험 경고를 덮는 불투명 원이나 연기, 긴 궤도 빔은 사용하지 않는다.

HUD 피해 숫자는 기본적으로 직접 삭제 주대상, 보스, 우선 목표, 약점 발동만 보인다. 잡몹의 다중 피해는 같은 `rootId`에서 합계 1개로 묶고 `3 CHAIN · 420`처럼 출처를 적는다. 위협이 화면 밖이면 가장자리 화살과 고정점 번호를 보여준다. 스킬 잔광보다 보스/고정점 경고가 언제나 마지막 합성 패스에서 그려진다. 원본처럼 업데이트 단계에서 그린 시각 효과가 다음 배경 프레임에 지워지지 않도록 전투 상태와 렌더 상태를 분리한다.

## 14. 사운드·접근성·성능 예산

**사운드 버스:** `DANGER`(고정점 피해·보스 경고) > `PLAYER`(스킬 사용·약점 개방) > `PROC`(전도·틱) 우선순위. 같은 `rootId`에서 PROC 음은 처음/마지막/중요 분기 최대 3개만 낸다. 감염 전파마다 소리를 내지 않는다. 보스 경고음은 효과음 음량에 묻히지 않게 별도 볼륨을 제공한다. 무음 플레이에서도 타이밍 원환·경고 아이콘이 같은 정보를 준다.

**저동작 모드:** 화면 흔들림·회전하는 장식·잔상·반복 펄스를 제거하고 정적인 단계환/진행 눈금/예고 선으로 타이밍 정보를 보존한다. LAST JUDGEMENT의 판정은 그대로 유지하고 현재선/다음 0.4초 판정 부채꼴만 0.1초 단계로 갱신한다. 어떤 모드에서도 전체 화면 백색 플래시를 쓰지 않는다. 고대비 모드는 적 윤곽을 한 겹 더 그리고 효과의 채도를 낮춘다. 색각 모드는 팔레트만 바꾸지 않고 지그재그/원환/사각/쐐기 형태와 아이콘을 유지한다. 피해 숫자 숨김, 큰 커서, 효과음/경고음 분리, 키 재설정, 툴팁 고정을 제공한다.

**초기 렌더 예산:** 화면에 동시에 보이는 장식 파티클 600개(저사양 220개), 뿌리당 세부 파티클 12개, 같은 프레임 동일 효과 8건 초과 시 하나의 면적 펄스로 합친다. 큰 지속 필드가 2개를 넘으면 세 번째부터는 외곽선만 그린다. 시각 품질을 낮출 때 제거 순서는 장식→잔광→반복 타격→일반 적의 개별 상태 글리프 압축 순이며 위험 예고·커서·보스/우선 목표 약점·해당 대상 상태 타이머는 절대 제거하지 않는다. 120–180적과 64개 후속 이벤트 상황에서 보스/고정점 신호의 가독성과 입력 지연을 측정한다.

**콘텐츠 데이터 항목:** 각 효과에는 `effectId`, `source`, `tags`, `baseDamage`, `cooldown`, `radius`, `duration`, `telegraphMs`, `maxTargets`, `procCost`, `maxPerRoot`, `statusGlyph`, `vfxShape`, `timingCue`, `soundCue`, `renderPriority`, `lodGroup`, `reducedMotionVariant`를 둔다. 카드 문구·타격 판정·예고 그림이 서로 다른 숫자를 읽지 않도록 동일 정의에서 파생한다. 이 문서는 데이터 계약이지 코드 구현 요구가 아니다.

## 15. 밸런스 가설과 실제 조정 기준

첫 상대 척도는 Drifter HP 100, Channeler HP 170, Ward HP 220. 일반 적 체력 증가는 18분에 Drifter 약 200이 되는 **분당 약 4%**를 가설로 잡는다. [전체 보고서](./GAME_SYSTEM_DESIGN_REPORT.md)의 “분당 최대 약 8%”는 상한이며 매분 목표 증가율이 아니다. 8분 중간 보스 HP는 5,000–7,000, 18분 최종 보스 HP는 22,000–28,000을 첫 실험 범위로 두고, 실제 60–90초 평균 보스전 DPS를 측정해 정한다. 플레이 도중 빌드를 보고 보스 HP를 몰래 올리거나 내리지 않는다.

**분리해서 측정할 성능:** (1) 60초 군중/고정점 방어 성공률, (2) 보스 120초 내 처치율, (3) 첫 스킬 분기 체험 시간, (4) 8/13/16분 코어 사용률, (5) Final 도달률, (6) 세계 적응 약점 이용률. 같은 시드·성장량에서 최약 빌드의 보스 유효 DPS 또는 군중 방어 성공률이 최강 빌드의 70% 미만이라면 먼저 그 빌드가 **공통 대응 창에 접근할 수 있는지** 고친다. 피해량만 올려 문제를 덮지 않는다.

**첫 체험의 기대치:** 첫 90초에 스킬을 최소 3회, 첫 5분에 Branch와 Special을 각각 한 번, 중간 보스 직후 Evolution I을 체험한다. 한 스킬이 보통 적 1–2명을 확실히 제거하거나 밀집군에서 더 큰 가치를 만들되 직접 삭제의 우선 표적 결정은 남겨 둔다. 자동 펄스만으로도 잔몹은 정리되지만 Channeler와 Ward를 무시하면 INTEGRITY가 떨어져야 한다.

## 16. 구현 전에 통과할 판정 체크리스트

| 확인 상황 | 통과 기준 |
|---|---|
| 단일 보스만 남은 OVERCHARGE | 남은 갈래가 반환 피해로 바뀌고, 무의미한 허공 전도/무한 재시동이 없음. |
| VOID BOMB 폭발 전에 직접 삭제 | REMOTE FUSE가 있을 때만 조기 기폭. 원래 직접 피해 후 취약 상태를 적용한 순서가 설명과 일치. |
| BLACK HOLE 안의 보스 | 이동은 하지 않지만 틱·종료·Exposed 등 유효 효과를 받음. Mass는 잡몹 처치로만 쌓임. |
| SCREEN CUT의 교차점·잔상 | 의도한 2회 피해는 들어가되 `onHit` 파생 효과는 한 뿌리에서 과다 반복되지 않음. |
| ORBITAL의 같은 적 다단 포격 | 네 발 피해는 각각 정산, 소환 시너지 발동은 명세 한도만. `summonDamage`/`skillDamage` 중복 곱 없음. |
| 감염 3스택·만료·사망·조기 기폭 | 틱/기폭값이 일치. 같은 `statusOwnerRoot`의 5번째 이후 기폭도 피해는 정산하고 후속 발동만 막음. 다른 `triggerRoot`가 기폭해도 한 상태는 한 번만 터짐. |
| Final 분기 상호작용 | RECORD의 Branch별 유령 폭발, LIVING CIRCUIT의 FORK/NEEDLE 경로, LAST JUDGEMENT의 LATTICE/RAZOR 선이 각각 다른 판정으로 작동. EPIDEMIC SCRIPT는 Special 양쪽에서 사용 가능. |
| 입력 잠금과 이펙트 일치 | BLACK HOLE의 1.2초 B 지정/이후 재배치, 포격의 0.3초 잠금, RECORD의 0.8초 본 폭발, 감염의 0.5초 방향 창이 표시된 범위·시각에만 판정. |
| 태그 Final 선택 | 16분 코어에서 FINAL STROKE/REWRITE SEQUENCE의 태그·8회 행동 조건을 확인하고 스킬 Final과 중복 획득하지 않음. 획득 뒤 30초 내 입력 연습 가능. |
| 두 번째 스킬 3:30 보장 | 늦게 획득해도 다음 2회 일반 성장 안에 Branch가 나오고, 8분 진화 코어가 사라지지 않음. |
| 하이브리드 출현 | 필요한 실제 출처가 없으면 제안하지 않음. 얻은 뒤 첫 30초 안에 발동 가능한 목표를 제공. |
| 세계 적응·보스 이펙트 겹침 | 적응 약점과 채널/보스 위험 예고가 포격·폭발 위에 읽힘. 저동작·무음에서도 타이밍 파악 가능. |
| 같은 런을 여러 번 종료 처리 | 결과/해금은 한 번만 지급. 시각 효과 오류가 전투 판정·저장을 멈추지 않음. |

**최종 선택 기준:** 이펙트가 화려해도 발동 원인·피해 시점·다음 행동을 가리면 줄인다. 스킬은 수치가 높아졌다는 사실보다, 플레이어가 *다른 위치를 찍고, 다른 순서로 누르고, 다른 적을 우선 처리하게 되었는지*로 완성도를 판단한다.

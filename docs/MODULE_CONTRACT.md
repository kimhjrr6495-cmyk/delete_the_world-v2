# Implementation module contract

Static ES modules, no runtime dependencies. Canvas arena logical size 1280×760, UI outside arena. `src/engine.js` root owns state, enemy scheduling, damage, direct input, progression/telemetry. Do not edit other agents' files.

Game state: `width,height,time,phase,integrity,maxIntegrity,pressure,xp,level,kills,rng,seed,cursor:{x,y,down,hold,angle,dx,dy},enemies,anchors,fields,effects,skillSlots,tags,stats,methods:Set,owned:Set,bans:Set,relics:[],hybrid:null,charges,chargeTimer,heat,network,choices,choiceContext,damageStats,settings:{reducedMotion,lowEffects,sound,highContrast}`. Each slot `{id,branch:null,modifier:null,evolution:0,cd:0,uses:0,key}`. Tags CHAIN/INFECTION/SINGULARITY/SWARM/IMPACT/CASTER. Enemy `{id,type,x,y,r,hp,maxHp,shield,maxShield,speed,elite,boss,dead,statuses:{},age,channel,anchorIndex,adaptation,weakness,hitFlash}`.

Stats: `{power,directBonus,skillBonus,summonBonus,cdr,critChance,critDamage,autoRate,chargeRate,radiusBonus}`. All damage amounts are base values; `game.damage()` applies stats/weakness/boss chain coefficient exactly once.

Game APIs: `newRoot():number`, `damage(enemy,amount,source,meta):{killed,damage}` source DIRECT/AUTO/SKILL/SUMMON/STATUS, meta `{rootId,tag,crit,bypass,tick,effectId}`. `near(x,y,r,filter?)`, `nearest(x,y,r=Infinity,filter?)`, `arc(x,y,count,damages,meta,excludedIds=[]):enemy[]`, `status(enemy,type,options)`, `fx(kind,props)`, `schedule(delay,fn)`, `sound(name)`, `toast(text)`, `onCast(slot,rootId)`, `grantSkill(id)`, `heal(amount)`. `rng` is function giving [0,1). `field` objects are added to `game.fields` by skills; their update/removal belongs to SkillSystem. `fx` always adds `{kind,age:0,life,maxLife,...props}`.

`src/skills.js`: export `SkillSystem` constructor(game), methods `press(index)`, `release(index,heldSeconds)`, `update(dt)`, `onDirect(target,info)`, `onKill(enemy,source,meta)`, `addStatus(enemy,type,options)`, `cancelInput()`, `crossNetwork()`. info `{x,y,held,rootId,mark}`. Engine consumes `mark` before direct damage and produces mark-consumption chain; skills handle OVERCHARGE arm/discharge, infected expiry/kill/manual burst and their fields. SkillSystem owns cooldown decrement and ALL status timer updates. Status keys `mark,infected,exposed,rupture,burn,strain,stroke,lease`; values `{remaining,duration,stacks,rootId,originPosition,damage,...}`. Engine calls skill onKill after marking enemy dead, before reward. Skill callbacks should only use living enemies via near/nearest.

Field types `bomb,hole,residue,fire,command,seed,soil,seam,sweep,fold,trail,cone,network`. Common `{id,type,x,y,r,age,duration,remaining,color,rootId}`. Extra line `{x2,y2,width}`, sweep `{angle,length,width}`, hole `{mass}`, bomb `{damage}`, command `{shots:[{x,y,at,locked,fired}],radius}`, network follows cursor. Effects kinds `ring,line,arc,burst,text,slash,spawn,heal,hit,marker` with common position/color/life and optional `r,toX,toY,width,length,angle,text`.

`src/data.js`: exports TAGS, SKILLS array IDs `overcharge,bomb,hole,cut,orbital,seed`; each `{id,name,ko,tag,color,icon,description,cooldown,branches:[{id,name,description}],modifiers:[...],evolutionNames}`. ENEMIES dictionary. Export `getSkill(id)`, `makeChoices(game,context='level')`, `applyChoice(game,choice)`, `skillDescription(slot)`. Choices `{id,kind,title,tag,description,detail,slotIndex,selection,skillId}`. Contexts `level,second-skill,evolution,relic,hybrid,route`. applyChoice can mutate stats/tags/sets/slots and call grantSkill,toast,heal. Progression at 8/13/16 minute cores; branches/modifiers available within next two level choices. IDs for 12 methods: `conductive_scar,origin_echo,spore_census,patient_zero,orbit_shear,event_horizon,target_lease,relay_beacon,overkill,precision_window,after_cast,alternating_circuit`. Hybrid IDs per spec snake_case. Relics IDs `crossed_wires,lens,time_capsule,anchor_heart,swarm_clock,hollow_crown`, root handles their behavior. Core IDs starting skill IDs, bonuses on start can be implemented root. Tag Final IDs `final_stroke,rewrite_sequence`. All content in Korean, names retain English.

`src/render.js`: export `Renderer` constructor(canvas), `draw(game,dt=0)`. Logical 1280×760 drawing, high DPI wrapper can be root. Draw background/grid/arena, anchor warnings, enemy silhouettes per role, fields/effects/statuses, cursor/aim hints; boss and channel warnings last pass. Access game.skills for `{armed,routeUntil,held}` if needed. No DOM outside canvas. Field unknown types skip gracefully. Use shapes/palette from docs, decorative effect caps, reduced motion variants.

Root implements actual 12 method and 10 hybrid event handlers; data cards only select/store them. Storage/results/audio/UI belong root. Tests must verify real event effects, cooldowns/selection valid, end-run idempotency.

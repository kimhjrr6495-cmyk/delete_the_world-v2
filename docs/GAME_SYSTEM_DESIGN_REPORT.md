## 1. Executive Summary

**핵심 판타지:** 플레이어는 세계를 때려 부수는 존재가 아니라, 작은 결함 하나를 찾아 현실의 규칙을 다시 쓰는 삭제 설계자다. 직접 지정한 한 점이 전도·감염·중력·소환망을 타고 화면 전체의 붕괴로 번진다. 세계는 가장 많이 쓰인 삭제 경로를 학습해 봉합하지만, 봉합에는 반드시 새 균열이 생긴다. 플레이어는 그 균열을 찾아 빌드를 다시 운용한다.

**제품 형태:** 마우스 중심의 2D 화면형 로그라이트. 표준 런은 전투 18분과 최종 보스 최대 2분, 총 18–20분이다. 커서를 움직여 목표를 지정하고, 제한된 직접 삭제·스킬·배치형 시스템으로 전장을 편집한다. 이동 캐릭터나 탄막 회피를 주축으로 삼지 않는다. 초반 2분은 약점을 골라 작은 연쇄를 만드는 단계, 마지막 2분은 자신이 만든 시스템의 경로를 재배치하고 세계의 대응을 역이용하는 단계다.

**가장 중요한 결정:** 기본 자동 삭제를 처음부터 약하게 제공한다. 수동 클릭은 반복 노동이 아니라 *연쇄를 시작하거나, 우선 목표를 끊거나, 세계가 노출한 약점을 찌르는* 개입이다. 런 성장 선택은 수치 강화 20%, 작동 규칙 추가 35%, 다른 규칙 연결 30%, 진화 15%를 목표로 한다. 진화는 운 좋은 카드 소진의 부산물이 아니라 보스·목표 보상으로 계획할 수 있게 한다.

**범위 통제:** 런 재화는 VOID(경험치), REWRITE(선택지 조정), INTEGRITY(패배 자원) 세 가지로 제한한다. AFFINITY는 점수/조건이며 소비 재화가 아니다. 유물은 2칸, 하이브리드는 1칸, 액티브 스킬은 2칸이다. 전용 상점·장비 인벤토리·무한 세트 보너스는 첫 완성 범위에서 제외한다.

**검증 가능한 성공 기준:** 첫 90초 안에 첫 작동 방식 변화, 5분 전 첫 조건부 상호작용, 8분 보스 뒤 첫 진화, 13분 전 세계 대응과 그 약점의 명확한 표시, 마지막 2분에 직접 명령·스킬·자동망을 함께 운용하게 할 것. 승리·실패·중단 모두 결과가 같은 저장 경로를 거쳐야 한다.

### 현재 런의 실질적인 흐름

시작 스킬 선택 → 떠다니는 적을 연타/홀드 삭제 → VOID로 **대부분 수치 카드** 선택 → 주기적 우선 목표/프리즘을 잡으면 별도 메서드·스킬 강화 → 월드 티어 상승으로 체력 증가 → 삭제 수 단계 보스 또는 420초 최종 보스 → 무결성 0으로 실패하거나 최종 보스를 처치해 결과 화면. 우선 목표 보상도 `finishAugment()`를 사용해 일반 레벨 요구량을 올리고 현재 VOID를 지우므로 성장 리듬이 흔들린다(L539).

### 존재하지만 연결이 약하거나 끊긴 부분

- 과거 업그레이드 목록 `U`와 6개 `SYN`은 정의와 효과 코드가 남아 있으나 현재 일반 선택 풀에 들어가지 않는다(L504–507, L515–525). 안정도 하락·붕괴·엔트로피 정산 경로 역시 실제 런에서 도달하지 않는다(L203–205, L558–559).
- `statRadius`는 `clickRadius` 수치를 올리지만 실제 `radius()`가 그 값을 읽지 않아 카드의 약속대로 반경이 늘지 않는다(L203, L264, L541, L640).
- 메서드 후보 필터가 `requiredSkill` 또는 `universal`만 받으므로 `drone`/`hive`는 등장하지 않는다. 감염 친화도는 얻을 수 있는 카드만으로 하이브리드 요구 8/10에 닿기 어렵다. 일부 카드/하이브리드는 이름만 해금되고 효과 참조가 없거나 호출되지 않는 레플리카 함수에만 구현되어 있다(L276–326, L418–420, L510).
- `openSkillEvolution()`은 보유 스킬의 일반 강화가 하나라도 남으면 진화를 뒤로 미룬다. 따라서 `shock`의 세 강화 최대치 합계 13개를 먼저 소진해야 진화 카드가 보일 수 있다. 7분 표준 런에서는 진화 설계 대부분을 경험하기 어렵다(L240–244, L362–399, L553).
- 세계 적응은 현재 빌드별 처치·스킬·소환 의존도를 읽지 않는다. 사실상 직접 클릭 효율을 보고 체력 배율을 올리는 시스템이다(L250–252).
- `maybeDropRewrite()`는 획득 문구와 소리만 내며 조정 재화를 증가시키지 않는다. `rerollUsed` 등은 선언되어 있지만 일반 선택 UI에 리롤/BAN/LOCK이 없다(L83, L324, L527–539).
- 영구 강화의 `automation`/`knowledge`는 구매 메뉴에 있지만 효과 소비처가 확인되지 않는다. 승리 유물은 `locked:true` 항목과 잠금 미리보기만 만들 뿐 런 보상으로 사용되지 않는다(L552–553, L568–570).
- 런 데이터 화면은 존재하지 않는 `G.stats.crit`/`radius`를 읽고, 능력치 패널은 CSS로 숨겨져 있다. 중복 선언된 CROSS NETWORK 함수는 뒤쪽 선언이 앞쪽 구현을 덮는다(L56–58, L431–449, L648, L711–735). 이는 현재값을 추정할 때 뒤쪽 함수를 기준으로 봐야 한다는 뜻이다.

## 3. 반드시 유지해야 할 재미 요소

**A — 반드시 살릴 것.** (1) 작은 원형 삭제에서 갑자기 화면 전체로 번지는 연쇄: 이 게임의 가장 빠른 감정 보상이다. (2) 커서로 한 지점을 고르고 결과를 보는 직접 개입: 자동 전투와 구별되는 정체성이다. (3) 세계가 플레이를 알아차린다는 대사·시각 연출: 적응 시스템의 감정적 기반이다. (4) BLACK HOLE과 ORBITAL/CROSS NETWORK처럼 공간을 다시 설계하는 기술: 단순 피해량보다 행동을 바꾼다. (5) 우선 목표와 프리즘처럼 평소 목표를 잠시 바꾸는 존재: 전투 리듬을 만든다.

**B — 발전시킬 것.** 빌드 친화도는 카드 등장과 세계 관찰을 연결하는 공통 태그로 쓰고, 스킬 진화는 일정 시점에 도달 가능한 선택으로 바꾼다. 콤보/연쇄 열은 무한 피해 배수가 아니라 위험을 건 타이밍 도구로 쓴다. `RICH BLOOM`의 성장 정체 완충은 숨은 보정이 아닌 공개된 회복 목표로 만든다.

## 4. 현재 구조의 문제점

**C — 구조 문제.** 실제 선택의 상당수가 수치 카드라 레벨이 올라도 플레이 방식이 그대로다. 일반 적은 공격보다 체력/보상 변종이 많고, 보스도 체력 목표이므로 강해진 빌드에 새로운 판단을 요구하지 않는다. 별도 보상도 레벨 경험치를 지워 성장 손실처럼 느껴질 수 있다. 능력 설명·표시값·효과 코드의 불일치는 플레이어의 계획을 무너뜨린다.

**D — 삭제/완전 재설계.** 도달 불가능한 옛 업그레이드/시너지 표를 그대로 살리는 방식은 버린다. 모든 능력은 하나의 데이터 원천과 실제 효과 핸들러에 묶는다. 안정도 기반 5배 보너스 같은 수동적 저체력 이득은 의도적 위험 계약으로 재설계한다. 체력만 증가하는 적응과 고정 원형 보스는 새 대응/약점 패턴으로 대체한다. 자동 클릭은 늦게 등장하는 노동 면제 카드가 아니라 시작부터 있는 약한 기본 동작으로 옮긴다.

## 5. 새로운 게임의 핵심 컨셉

**한 문장:** “삭제 경로를 설계하면 세계가 그것을 봉합하고, 봉합의 균열을 이용해 더 큰 삭제망을 만드는 20분짜리 커서 전략 로그라이트.”

화면에는 적과 세 개의 **현실 고정점**이 있다. 적이 고정점에 채널링하면 INTEGRITY가 깎인다. 플레이어는 커서로 자동 삭제의 관심 위치를 옮기고, 직접 삭제로 고가치 대상/노출 약점을 찌르고, 두 액티브 스킬로 위치·시간·연쇄 경로를 만든다. 고정점은 지켜야 할 세부 오브젝트이자 폭발/전도의 환경 지형이다. 세계의 적응은 사용한 빌드를 닫는 동시에 특정 공격/위치에 취약한 균열을 만들어 다음 판단을 요구한다.

## 6. Design Pillars

1. **한 점에서 화면 전체로:** 작은 입력이 읽을 수 있는 규칙을 따라 커지는 연쇄. 모든 폭발/전도에는 원인과 경로가 보인다.
2. **명령의 질이 클릭의 양을 이긴다:** 수동 입력은 타이밍·표적·배치 결정이다. 홀드 연타가 최적해가 되지 않는다.
3. **세계는 대응하면서 빈틈을 드러낸다:** 적응은 최대 약 25%의 국지적 저항과 동등한 약점을 함께 준다. 완전 면역은 없다.
4. **빌드마다 전장을 보는 방식이 다르다:** 감염은 시간, 특이점은 위치, 소환은 자동망, 충격은 개별 타격, 연쇄는 밀도, 캐스터는 순서에 집중한다.
5. **실패도 다음 가능성을 연다:** 영구 보상은 원칙적으로 신규 선택지/사건/규칙을 열고, 기본 화력 영구 누적은 최소화한다.

## 7. Core Gameplay Loop

1. **런 시작:** 해금한 코어 3개 중 1개와 시작 액티브 3개 중 1개 선택. “이번 판에 어떤 사건을 자주 만들지?”를 정한다.
2. **전투:** 커서 자동 펄스로 약한 적을 정리하고, 2충전 직접 삭제로 연쇄의 첫 목표·채널러·취약 노드를 지정한다. “지금 클릭해야 가장 큰 결과는 어디인가?”를 생각한다.
3. **획득/성장:** 적의 VOID는 자동 흡수된다. 레벨업 3장 중 하나에서 작동 규칙을 선택한다. “현재 규칙을 깊게 할까, 약점을 보완할까?”를 판단한다.
4. **첫 시너지:** 두 태그의 작동 조건이 맞으면 고유 효과가 열린다. “빌드의 엔진이 무엇인가?”가 명확해진다.
5. **세계 대응:** 전투 기록을 토대로 대응 세력이 나타나고 약점이 함께 노출된다. “같은 기술을 어떤 순서/위치에서 써야 하는가?”로 사고가 바뀐다.
6. **위험 계약/중간 보스:** 보상 종류를 미리 보고 더 위험한 경로를 선택한다. 승리 시 진화 코어를 얻고 한 기술의 행동 규칙을 바꾼다.
7. **후반 조합:** 유물·하이브리드·진화가 맞물려 대규모 자동망이 생긴다. 플레이어는 망을 감시·재배치·예외 처리한다.
8. **최종 보스/정산:** 보스는 현재 주력 경로를 봉합하되 약점을 드러낸다. 승리 또는 실패 후 같은 정산 화면에서 원인, 빌드, 메타 보상, 새 해금을 보여준다.

## 9. Combat System

**기본 조작.** 커서는 물리적 체력이 없는 지휘점이다. 커서 반경 110px 안의 가장 가까운 적에게 약한 자동 펄스가 0.9초마다 1회 발사된다. 좌클릭은 **직접 삭제**로, 2충전·충전당 2.8초 회복·최소 입력 간격 0.25초다. 충전이 없을 때 클릭은 추가 공격을 만들지 않는다. 클릭을 0.35–1.2초 눌러 놓으면 반경을 키우는 대신 위치를 예고하고 놓을 때 1회 강타한다. 충전은 버튼을 놓아 공격이 확정될 때 1개 소모하며, 창 포커스를 잃거나 선택 화면이 열려 취소되면 소모하지 않는다. E/Q는 선택한 두 액티브, ESC는 일시정지와 빌드 정보다. T/F 같은 추가 키는 최종 진화에서만 HUD 설명과 함께 열린다. 게임패드는 조준 이동/버튼으로 동등하게 조작한다.

**목표와 패배.** 세 현실 고정점 중 하나에 채널러가 붙으면 2초 예고 후 INTEGRITY가 초당 1씩 감소한다. 엘리트 채널은 초당 2다. INTEGRITY 0 또는 최종 보스의 120초 제한 만료가 패배. 보스와 적은 플레이어 커서를 직접 죽이지 않는다. 고정점은 한 화면에 분리되어 있어 적을 묶을 장소와 방어 우선순위를 선택하게 한다. INTEGRITY 100 시작, 일반 회복은 8/13분 보스 이후 각 15 한도다.

**피해/상호작용 계약.** 모든 공격 이벤트에는 `source`, `owner`, `tags`, `rootId`, `generation`, `damage`, `position`, `radius`, `procBudget`가 있다. 처치 이벤트는 `onHit` → `onKill` → `onExpire` 순으로 처리한다. 같은 뿌리의 같은 효과는 대상당 한 번만 발동하며, 기본 최대 세대 5·한 뿌리 64개 후속 이벤트·프레임당 256개를 초기 상한으로 둔다. 상한에 닿으면 시각 효과는 합쳐서 표시하고 피해는 면적/대상 우선순위에 따라 정산한다. 중요 목표 피해가 후순위로 유실되지 않게 한다. 이 계약이 있어야 CHAIN+INFECTION 같은 순환형 진화가 예측 가능하고 성능도 지킨다.

**크리티컬/중첩.** 기본 크리티컬은 직접 삭제에만 적용하며 확률 최대 60%, 추가 피해는 피해 계산 마지막에 곱한다. 동일 종류의 지속 피해는 피해를 무한 중첩하지 않고 강한 효과 1개+최대 3스택의 지속시간 갱신으로 제한한다. 보스에 대한 연쇄 피해는 60%부터 시작해 테스트로 조정하되 면역으로 만들지 않는다. 표준 빌드가 잡몹과 단일 목표 모두에 최소한의 대응 수단을 갖도록 모든 코어에 기본 직접 삭제를 남긴다.

## 10. Player Growth System

**한 런의 목표 성장량:** 약 14–18회의 일반 선택, 진화 코어 3회, 유물 2회, 하이브리드 1회. 유물/하이브리드를 제외한 **런 전체 성장 선택**의 실제 획득 결과가 STAT 약 20% / MECHANIC 35% / SYNERGY 30% / EVOLUTION 15%가 되도록 추적한다. EVOLUTION은 주로 고정 보상에 배치하며 수치 카드는 빈 선택을 막는 안전망이다. 세 장 중 한 장을 고르는 각 일반 선택 화면에는 현재 빌드에 유효한 비수치 카드가 적어도 한 장 있어야 한다.

**단계:** `STAT`는 한계값 보정(예: 직접 삭제 충전 회복 +0.2초)만 한다. `MECHANIC`은 새 동작(처치 시 표식, 블랙홀 질량 축적)을 연다. `SYNERGY`는 두 동작의 순서/조건을 연결한다. `EVOLUTION`은 기술의 역할을 바꾼다. 예: 한 적을 직접 삭제 → 주변 2명에게 전도 → 전도 생존자 표식 → 표식 처치 시 폭발 → 폭발이 남은 전도 목표를 찾아 다시 이동. 각 단계는 전투 로그와 화면 아이콘에서 구별된다.

**VOID 곡선:** 처치 VOID는 자동 수집. 다음 레벨 요구량은 1–4레벨 완만, 5–12레벨 선형에 가깝게 증가, 이후 완만한 지수로 전환한다. 목표는 일반적인 숙련 플레이에서 90초 첫 선택, 5분 5–6회, 12분 11–13회, 18분 15–18회다. 초과 VOID는 항상 다음 레벨로 이월한다. 특수 보상은 VOID와 레벨 카운터를 건드리지 않는다. 90초간 선택이 없으면 다음 우선 목표에 추가 VOID를 넣어 정체를 끊고, 숙련 빌드의 과잉 획득은 보상 선택 수를 무한히 늘리지 않도록 레벨 간 요구량으로 흡수한다.

## 11. Build System

여섯 방향은 **행동 동사**로 구별한다: CHAIN은 *시동 걸기*, INFECTION은 *기다리고 터뜨리기*, SINGULARITY는 *모으기*, SWARM은 *배치·우선순위 지정*, IMPACT는 *한 발을 준비하기*, CASTER는 *순서 맞추기*. `CONDUCTION`은 CHAIN의 전도 하위 태그, `EXPLOSION`은 공통 효과 태그로 둔다. 빌드 태그 점수는 카드에 적힌 1–2점으로만 증가하며 피해량에 의해 임의로 변하지 않는다. 4점에서 해당 메서드 출현 가중치 증가, 6점에서 전용 카드 풀, 서로 다른 두 태그가 각각 4점이면 하이브리드 제안 자격을 얻는다. 숫자가 보이지 않는 숨은 조건을 없앤다.

플레이어는 한 주력 태그와 한 보조 태그를 보통 완성한다. 두 액티브 슬롯 중 하나를 보조 약점 대응용으로 유지할 수 있다. 하이브리드 슬롯은 1개이며 13분 보상 때 한 번 무료 교체할 수 있다. 복수 빌드 전부를 동시에 완성하는 방식은 슬롯과 진화 코어 때문에 불가능하다.

## 12. 각 Build 상세

### CHAIN — 연쇄 설계자

- **핵심/초반:** 밀집된 약한 적의 시작점을 고른다. 직접 삭제 처치 시 가까운 미타격 적 2명에게 낮은 피해가 이어진다.
- **중반/후반:** 전도 방향을 고정점 주변으로 유도하고, 표식이 쌓인 대상을 골라 2차 파동을 만든다. 후반에는 연쇄를 흘려보낼지 `CHAIN HEAT`를 의도적으로 터뜨릴지 고른다.
- **대표 능력/시너지:** `Conductive Scar`는 전도 생존자에 표식. `Return Current`는 표식 처치 시 첫 노드로 신호 회귀. **최종 진화 `Closed Circuit`:** 회귀한 신호가 경로의 균열을 열어 직접 삭제 피해를 증폭한다.
- **강점/약점/Hybrid:** 군집 처리와 VOID 속도가 좋다. 흩어진 단일 목표·차단 노드에 약하다. INFECTION과 결합하면 감염이 전도 경로를 타고 이동한다.

### INFECTION — 잠복 편집자

- **핵심/초반:** 대상에 지연 표식을 심고 3초 뒤 터질 군집을 만든다. 즉시 처치보다 감염자 간 거리 유지가 중요하다.
- **중반/후반:** 감염 기간 동안 고정점에 접근하는 적을 골라 조기 폭발시키거나, 큰 집단을 기다려 한꺼번에 발화한다. 후반에는 감염된 적의 사망 위치에 잠복 구역을 남긴다.
- **대표 능력/시너지:** `Carrier`는 감염자가 가까운 적에게 옮긴다. `Patient Zero`는 첫 감염자가 죽을 때 주변 감염의 남은 시간을 폭발 피해로 전환. **최종 진화 `Epidemic Script`:** 직접 삭제로 발화한 영역이 1회 새로운 감염원을 만든다.
- **강점/약점/Hybrid:** 넓은 공간 선점과 시간차 폭발에 강하다. 급한 단일 목표에는 느리다. SWARM과 결합하면 소환체가 감염을 운반한다.

### SINGULARITY — 위치 조각가

- **핵심/초반:** 끌어당길 중심점을 정한다. 직접 삭제 한 번의 피해보다 적을 모으는 위치가 중요하다.
- **중반/후반:** 블랙홀에서 쌓인 질량으로 압축 충격을 만들고, 적응 변이의 약점을 노출할 위치에 집단을 놓는다. 후반에는 둘로 나뉜 중심을 합쳐 긴 폭발 경로를 만든다.
- **대표 능력/시너지:** `Mass Ledger`는 블랙홀 내부 처치 질량 저장. `Event Horizon`은 질량이 찼을 때 재배치 가능. **최종 진화 `Reality Fold`:** 두 중심을 접어 그 사이의 적과 보호 연결을 잘라낸다.
- **강점/약점/Hybrid:** 적 배치와 보호망 분리에 강하다. 이동이 빠른 표적과 긴 재사용 시간에 약하다. CASTER와 결합하면 스킬 순서가 중력장을 바꾼다.

### SWARM — 자율망 지휘자

- **핵심/초반:** 드론/레플리카가 때릴 우선 영역을 커서로 지정한다. 자동망은 처음부터 부분적으로 작동하지만 목표 선택은 플레이어가 한다.
- **중반/후반:** 포격을 고정점 방어에 배치할지 희귀 목표 추적에 배치할지 결정한다. 후반에는 네트워크 교차점을 직접 옮겨 피해 경로를 만든다.
- **대표 능력/시너지:** `Target Lease`는 4초 표적 지정, `Relay Beacon`은 소환체가 처치한 위치에 릴레이 생성. **최종 진화 `Cross Network`:** 두 축의 레이저 교차점이 표식/질량 등 다른 빌드 효과를 증폭한다.
- **강점/약점/Hybrid:** 다른 일에 집중하면서 안정적인 제압이 가능하다. 갑작스러운 원거리 채널러와 소환체 공격자에 약하다. INFECTION과 결합하면 드론이 잠복 감염원을 심는다.

### IMPACT — 한 발의 파괴자

- **핵심/초반:** 높은 체력이나 보호자를 고른다. 직접 삭제 충전을 아끼고 약점 창에 맞춘다.
- **중반/후반:** 초과 피해를 주변 균열로 바꾸고, 스킬이 만든 노출 상태에 큰 타격을 넣는다. 후반에는 작은 공격을 축적한 뒤 한 번의 재작성 명령으로 폭발시킨다.
- **대표 능력/시너지:** `Overkill`은 초과 피해를 반경 피해로 전환. `Precision Window`는 약점 노출 후 첫 직접 삭제가 보호를 관통. **최종 진화 `Final Stroke`:** 최대 충전 타격이 처치하지 못한 적에도 균열을 남겨 다음 다른 출처 피해를 증폭한다.
- **강점/약점/Hybrid:** 엘리트/보스와 고가치 목표에 강하다. 다수 처리·쿨다운 빈틈에 약하다. CHAIN과 결합하면 큰 타격의 균열에서 관통 신호가 출발한다.

### CASTER — 순서 조율자

- **핵심/초반:** E/Q의 역할을 나눠 쓴다. 먼저 묶기/표식, 다음 폭발/절단으로 순서를 설계한다.
- **중반/후반:** 스킬 사용 후 직접 삭제에 짧은 보너스 창을 열고, 서로 다른 스킬의 교대 사용으로 재사용 시간을 일부 돌려받는다. 후반에는 두 스킬의 조합이 세 번째 효과를 만든다.
- **대표 능력/시너지:** `After Cast`는 2초 내 직접 삭제 변형, `Alternating Circuit`은 다른 스킬을 연속 사용 시 전장 효과 변경. **최종 진화 `Rewrite Sequence`:** E→Q→직접 삭제를 5초 안에 완성하면 현재 약점 태그에 맞는 일회성 재작성 발생.
- **강점/약점/Hybrid:** 대응력과 순간 전환이 뛰어나다. 조작/쿨다운 관리 난도가 높다. SINGULARITY와 결합하면 스킬 시전 위치가 중력장의 새로운 중심이 된다.

## 13. Cross-Build / Hybrid

서로 다른 태그가 각 4점 이상일 때 아래 조합의 **고유 하이브리드 카드**가 특수 보상 풀에 들어온다. 획득해야 발동하며, 장착 슬롯은 1개다. 효과는 두 숫자의 합이 아니라 발동 순서·대상·공간을 바꾼다. 아래 15개는 전체 6태그 쌍을 포괄하며, **첫 제작 범위는 앞의 10개**다.

| 조합 | 하이브리드 효과와 플레이어 행동 변화 | 범위 |
|---|---|---|
| CHAIN + INFECTION | **Contagion Circuit:** 전도된 감염자의 사망이 남은 전도 경로로 잠복 감염을 1회 운반한다. 시작 노드를 군집 가장자리에 잡는다. | 최초 |
| CHAIN + SINGULARITY | **Orbit Relay:** 블랙홀 안의 적을 순회한 전도가 밖으로 튀어나올 때 저장 질량을 소모해 새 출구를 만든다. 홀의 위치가 연쇄 방향을 결정한다. | 최초 |
| CHAIN + SWARM | **Relay Hunt:** 소환체가 표시한 목표를 직접 삭제하면 가장 가까운 릴레이에서 전도가 재출발한다. 소환망과 직접 타격을 번갈아 운용한다. | 최초 |
| CHAIN + IMPACT | **Railgun Scar:** 충전 타격의 초과 피해가 관통 전도선을 만든다. 긴 직선상의 보호자를 고른다. | 최초 |
| CHAIN + CASTER | **Echo Order:** E 뒤 Q로 생성된 첫 전도는 0.4초 뒤 같은 출발점에서 다른 미타격 적에게 한 번 재경로를 찾는다. 스킬 순서를 맞춘다. | 최초 |
| INFECTION + SINGULARITY | **Quarantine Collapse:** 홀 안의 감염이 퍼지지 않고 압축되다가 홀 종료 시 외곽에 일괄 방출된다. 터뜨릴 시점을 계획한다. | 최초 |
| INFECTION + SWARM | **Parasite Hive:** 드론이 약화한 적에게 감염을 싣고, 직접 지정한 표적에 우선 전파한다. 원거리 채널러를 조준한다. | 최초 |
| INFECTION + IMPACT | **Patient Zero:** 최대 충전 직접 삭제가 감염자의 남은 잠복 시간을 즉시 폭발로 바꾼다. 큰 타격을 기다릴 이유가 생긴다. | 최초 |
| INFECTION + CASTER | **Delayed Script:** 첫 스킬이 심은 감염을 다른 스킬이 조기 기폭하면 해당 스킬의 재사용 시간이 일부 회복된다. 두 스킬을 교대한다. | 최초 |
| SINGULARITY + SWARM | **Cross Gravity:** CROSS NETWORK의 교차점이 홀의 중심을 짧게 끌고 와 이동식 압축선을 만든다. 교차점을 재배치한다. | 최초 |
| SINGULARITY + IMPACT | **Dense Shot:** 홀에 압축된 질량을 직접 타격으로 인출해 한 줄의 방어 연결을 끊는다. 질량을 쓰는 대상을 고른다. | 후속 |
| SINGULARITY + CASTER | **Void Architect:** E/Q를 다른 장소에서 쓰면 두 위치 사이에 짧은 중력 통로가 생긴다. 시전 위치를 계획한다. | 후속 |
| SWARM + IMPACT | **Execution Contract:** 소환체는 적을 처치하지 않고 약점만 누적한다. 직접 삭제가 목표를 마무리하면 포격 배치가 갱신된다. | 후속 |
| SWARM + CASTER | **Command Buffer:** E/Q 사용이 드론의 다음 표적 명령을 저장했다가 동시에 실행한다. 순서와 대상을 조정한다. | 후속 |
| IMPACT + CASTER | **Final Syntax:** 스킬 두 종류가 남긴 서로 다른 표식 위에 충전 직접 삭제를 넣으면 보스 약점 창이 열린다. 스킬을 보스 패턴에 맞춘다. | 후속 |

모든 하이브리드는 `trigger`, `consumes`, `applies`, `cooldown`, `maxPerRoot`를 데이터로 갖는다. 동일 뿌리에서 두 하이브리드가 재귀적으로 서로를 부르는 구조는 슬롯 1개와 `maxPerRoot=1`로 방지한다. 하이브리드와 유물 때문에 전투가 너무 자동화되면 직접 지정할 표적/위치 결정을 남기는 방향으로 효과를 고친다.

## 14. Skill System

액티브는 두 슬롯. 시작 스킬 1개, 이상체/중간 목표에서 두 번째 스킬 1개를 얻는다. **Base → Branch(A/B 택1) → Special Modifier(1개 택1) → Evolution I → Evolution II → Final Evolution** 순서다. Branch는 첫 3분 내, Special은 첫 보스 전, Evolution I은 8분 보스 보상, II는 13분 지휘자 보상, Final은 16분 균열 시련 보상으로 한 기술에 집중하면 확정 도달 가능하다. 진화 보상을 서로 다른 스킬에 나누면 둘 다 중간 단계에 머문다. 진화 조건이 안 되면 이유와 다음 충족 목표를 사전에 보여준다.

| 스킬 | Base와 Branch A/B | Special Modifier | Evolution I → II → Final의 **행동 변화** |
|---|---|---|---|
| **OVERCHARGE** | 다음 직접 삭제에서 근처 적 3명에게 전도. A **Fork**: 넓은 약한 분기. B **Needle**: 보호자 우선 관통. | `Grounding`: 고정점에 닿은 전도가 방어용 접지파를 남김 / `Capacitor`: 전도 생존자 표식. | I: 생존자 표식. II: 표식 처치가 1회 재전도. Final **Living Circuit**: 플레이어가 다음 출발점 1개를 직접 찍어 경로를 교정; 5초마다 자동 시동은 약한 버전. |
| **VOID BOMB** | 지정 지점에 0.8초 뒤 폭발. A **Cluster**: 작은 2차 폭탄. B **Compression**: 작은 범위에 강한 폭발. | `Remote Fuse`: 직접 삭제로 조기 기폭 / `Delayed Return`: 폭발 뒤 잔류 구역. | I: 폭발이 적을 중심으로 밀어 후속 경로 생성. II: 처치 수에 따라 다음 폭탄의 지연/위치가 달라짐. Final **Total Void**: 충전 중 축적한 삭제 기록을 지정 구역에서 한 번 재생; 화면 전체 즉사 대신 위치 결정이 남는다. |
| **BLACK HOLE** | 3초 동안 한 지점으로 끌어당김. A **Twin**: 작은 두 중심. B **Anchor**: 큰 고정 중심. | `Mass Ledger`: 내부 처치로 질량 축적 / `Tidal Pull`: 빠른 적의 이탈 속도 감쇠. | I: 질량에 따라 종료 충격. II: 지속 중 중심 1회 재배치. Final **Reality Fold**: 두 중심을 접어 사이 적과 방어선을 잘라냄; 모으기에서 공간 편집으로 역할 변경. |
| **SCREEN CUT** | 커서 방향 선을 따라 적중. A **Lattice**: 교차선. B **Razor**: 좁고 긴 관통선. | `Afterimage`: 같은 선을 0.5초 뒤 재절단 / `Rupture`: 맞은 적에 다음 직접 삭제 약점. | I: 절단면에 2초 균열이 남음. II: 다른 절단선과 교차하면 그곳에 폭발. Final **Last Judgement**: 회전하는 선의 기점 1개를 플레이어가 옮겨 채널러/보스 약점을 겨냥. |
| **ORBITAL COMMAND** | 밀집 구역에 레플리카 2기가 순차 포격. A **Watchtower**: 고정점 방어. B **Hunter**: 우선 목표 추적. | `Marked Target`: 직접 삭제가 다음 포격을 같은 지점에 예약 / `Incendiary`: 포격 후 짧은 잔류 화염. | I: 표적을 착탄 직전까지 갱신. II: 포격 구역 1개를 수동 지정. Final **Cross Network**: 포격이 두 축의 교차 네트워크가 되어, 교차점을 움직여 집중 피해/약점 노출을 제어. |
| **LATENCY SEED** *(신규)* | 적 한 명에 3초 감염 씨앗. A **Carrier**: 이동 전파. B **Reservoir**: 확산 대신 누적. | `Manual Detonate`: 직접 삭제로 조기 폭발 / `Dormant Soil`: 처치 지점에 잠복 구역. | I: 감염자의 이동 경로를 따라 짧은 흔적. II: 감염 사망을 1회 다른 호스트로 이식. Final **Epidemic Script**: 플레이어가 한 집단을 조기 기폭하면 살아남은 감염이 다른 방향으로 재배치. |

Branch/Modifier의 정확한 피해량·쿨다운은 플레이테스트에서 맞춘다. **작동 문장과 선택 간 상호 배타성**은 구현 계약이다. 스킬 사용은 강한 버튼이 아니라 위치/순서/시동/약점 노출을 만든다. 스킬 진화 IV가 일반 강화 10여 개 소진 뒤에야 열리던 기존 의존성은 제거한다.

## 15. Upgrade System

**선택지 생성 계약:** 카드마다 `id, category, rarity, tags, prerequisites, conflicts, maxRank, effectId, offerWeight, unlockId`를 둔다. 정의는 한 곳이며 `effectId`가 실제 이벤트 핸들러에 등록되지 않으면 빌드 검증에서 오류로 처리한다. 일반 레벨 화면은 정확히 3장: 현재 주력/후보 태그 관련 1장, 넓은 풀 1장, 약점 보완 또는 아직 못 본 규칙 1장. 조건 불충족 카드는 카드 풀이 아니라 도감의 “필요 조건”에서만 보인다. 동일한 3장 중복은 없다.

**가중치 초기안:** 처음엔 태그 중립; 태그 4점 이상이면 관련 카드 가중치 ×1.6, 다른 태그는 바닥 확률 0.35를 유지한다. 일반/희귀/매우 희귀의 기본 후보 가중치 70/25/5. 보유한 기계적 능력을 연결하는 시너지 후보는 조건을 만족하면 해당 슬롯에서 가중치 ×2. 첫 3회 일반 선택 안에는 메커닉 카드 1개 이상을 확정 제시하고, 4회 연속 희귀 이상을 *선택할 기회*가 없으면 다음 화면에 희귀 1장 확정한다. Pity는 카드의 선택을 강요하지 않고 등장만 보장한다. 확률은 시드 RNG로 고정돼 리플레이·버그 재현이 가능하다.

**선택권:** 한 런 REWRITE 2충전으로 시작, 우선 목표/경로에서 최대 2충전 더 얻는다. `REROLL` 1충전: 현재 세 장 전체 재추첨, 직전 카드 제외. `BAN` 1충전: 카드 1종을 **이번 런** 후보에서 제거하고 그 자리를 즉시 교체, 최대 2회. `LOCK` 1충전: 카드 1장을 다음 일반 레벨업의 세 자리 중 하나에 유지; 다음 화면에서 반드시 선택해야 하는 것은 아니다. 같은 화면에 REROLL/BAN/LOCK을 반복 적용해 확정 빌드를 만드는 것을 막기 위해 조정은 화면당 1회만 허용한다. REWRITE는 전투 수치에 직접 쓰이지 않는다.

**희귀도와 슬롯:** 일반 레벨업은 STAT/MECHANIC/SYNERGY. 특별 목표는 METHOD 또는 REWRITE, 보스/엘리트는 RELIC 또는 진화 코어. 진화는 같은 3장 일반 풀과 섞이지 않는다. 이미 최대 랭크인 카드, 장착할 슬롯이 없는 유물, 얻을 수 없는 하이브리드는 풀에서 제외한다. 슬롯이 막혔다면 명시적인 교체 화면을 연다. 모든 카드 툴팁은 현재 효과, 선택 후 바뀌는 행동, 발동 조건, 보유 태그 변화, 약점 대응 여부를 보여준다.

## 16. Synergy System

**시너지의 정의:** 두 개 이상의 실제 동작이 연결돼 새 입력 판단을 만들면 시너지다. 단순 `+20%`는 시너지로 세지 않는다. `onDirectHit`, `onKill`, `onSpread`, `onCast`, `onMassThreshold`, `onAnchorThreat`, `onAdaptedEnemy` 등 표준 이벤트만 사용한다. 예를 들어 `Conductive Scar`의 `onHit`가 감염 표식을 남기고 `Patient Zero`의 `onKill`이 그 표식을 폭발로 바꾼다. 각 카드와 하이브리드에는 **발동 조건–결과–최대 빈도–시각 표식** 네 가지를 반드시 명시한다.

초기 구현할 로컬 시너지 8종은: 전도+표식, 감염+조기 기폭, 질량+폭발, 포격 표적+직접 삭제, 절단 균열+직접 삭제, 직접 초과 피해+주변 파열, E/Q 교대+쿨다운 회복, 연쇄 열+마지막 재시동. 하이브리드는 이 위에 한 층만 쌓는다. 한 처치의 후속 효과를 세대 5까지 추적할 수 있도록 전투 로그에서 `rootId`를 보여준다. 스크린 연쇄가 발생해도 어떤 선택이 원인인지 플레이어가 이해해야 한다.

## 17. Evolution System

**자원과 시점:** 8분 중간 보스, 13분 지휘자, 16분 균열 시련이 각각 진화 코어 1개를 준다. 코어는 즉시 사용해 보유 스킬 한 개를 한 단계 올린다. 선행 Branch/Modifier가 없으면 먼저 그 선택을 무료로 제공한다. 한 기술에 세 코어를 쓰면 그 런에서 Final Evolution이 확정 가능하다. 선택 화면에서 다른 기술에 분산할 경우 예상 최종 도달 단계를 미리 보여준다.

**진화 가드레일:** Final에는 주력 태그 6점 또는 관련 하이브리드 획득 중 하나만 필요하다. 조건이 미충족이어도 코어를 버리지 않고 90초 동안 보관하거나 다른 스킬에 사용할 수 있다. 진화 직후 30초 안에 새 규칙을 체험하게 할 적/목표를 스케줄러가 제공한다. Final은 화력 배수보다 행동 변화를 가져야 하며, HUD에 새 키/충전/위치 선택을 즉시 설명한다.

## 18. Enemy System

| 적/역할 | 플레이어에게 묻는 질문 | 읽을 수 있는 약점/보상 |
|---|---|---|
| **Drifter** 기본 | 군집 시작점을 어디로 잡을까? | 모든 효과가 정상 작동; 낮은 VOID. |
| **Ward** 보호자 | 보호 연결을 먼저 끊을까, 바깥 적을 돌릴까? | 보호선 끝이 직접 타격/절단에 약함. |
| **Channeler** 고정점 위협 | 현재 연쇄를 이어갈까, 방어로 전환할까? | 2초 채널 예고 중 직접 삭제에 노출. |
| **Splitter** 죽을 때 분열 | 폭발로 처치할지 단일 공격으로 마무리할지? | 직접 삭제 처치 시 분열 억제. |

적은 체력만 늘리지 않는다. 각 적의 위협 동작에는 **예고 ≥1초, 눈에 보이는 원인, 범용 대응 하나, 특정 빌드 대응 하나**가 있어야 한다. 엘리트는 위 역할 둘을 섞되 동일 화면에 강한 봉합 역할은 최대 2종. 기본 적 HP 증가율은 1분당 최대 약 8%의 초기 상한을 두고, 어려움은 채널·보호·분열 조합 및 배치로 올린다. 적 수는 화면 읽기/성능을 위해 기준 동시 120, 하드 캡 180으로 시작해 측정 후 조정한다.

## 19. World Adaptation System

**관찰:** 최근 45초 중 보스전과 일시정지를 제외한 피해·처치 기록을 `DIRECT, CHAIN, INFECTION, SINGULARITY, SUMMON, SKILL, CRITICAL`로 집계한다. 동일 처치가 여러 태그에 중복 기여하지 않게 최종 원인 60%, 경로 기여 40%로 나누며 한 처치의 총 기여값은 1이다. 중력처럼 제어가 주역인 효과는 그 효과로 이동한 적이 3초 안에 처치되면 경로 기여로 기록한다. 30처치 미만이면 표본 부족으로 적응을 미룬다. 6분·11분·16분 전후의 예정 시점에 주력 방식 비중 ≥45%이고 2위보다 ≥15%p 높으면 대응 1종을 고른다. 그렇지 않으면 중립 변이 이벤트를 고른다. 적응은 **사용량을 벌주기 위한 숨은 보정**이 아니라 예고된 선택 문제다.

| 감지된 의존 | 세계의 대응 | 동시에 생기는 균열 |
|---|---|---|
| CHAIN | 일부 Ward가 첫 전도 1회를 흡수 | 보호선 끝은 직접 삭제/절단에 받는 피해 +30% |
| INFECTION | Scrubber가 주변 잠복 시간을 늦춤 | 정화 중 정지하며 충전 삭제/포격에 +30% |
| SINGULARITY | Anchor가 끌림을 부분 저항 | 중심 밖으로 밀린 순간 폭발/절단에 +30% |
| SWARM | Jammer가 일부 자동 표적을 흐림 | 교란 중 본체는 직접 삭제에 +30% |
| IMPACT/CRITICAL | Mirror가 같은 뿌리의 두 번째 큰 타격을 낮춤 | 약한 다단 타격으로 균열을 먼저 열 수 있음 |
| CASTER/SKILL | 침묵 맥동이 시전 지점 하나를 2초 예고 | 예고 지점을 벗어난 스킬이 실드를 벗김 |

**상한·공정성:** 적응 개체는 일반 적의 25–35%까지만 섞고, 한 런 활성 적응은 최대 2개. 새 대응이 들어와 상한을 넘으면 가장 오래된 대응이 종료된다. 대응 피해 경감은 최대 25%; 완전 면역·전체 화면 적용은 금지. 새 균열은 실제 대체 행동으로 이용할 수 있어야 한다. 적응 30초 전에 HUD가 `관찰: CHAIN 58% → Ward 봉합 예상`을 보여주고, 발생 뒤에는 약점 아이콘과 짧은 시험 목표를 준다. 같은 대응이 두 번 연속 나오지 않는다. 최근 60초간 INTEGRITY 손실이 큰 플레이어에게는 새로운 대응을 30초 지연한다. 적응을 극복하면 VOID/REWRITE 또는 유물 선택 가중치 보상을 얻는다.

## 20. Event System

이벤트는 **세계 사건(30–60초)**과 **경로 결정(8·13·16분 뒤)** 두 층이다. 세계 사건은 군집 유입, 금빛 고가치 표적, 고정점 오염, 취약 균열, 성장 정체 회복 목표에서 한 번에 하나만. 이전 사건이 끝나면 최소 25초 쉬고, 같은 사건은 연속으로 나오지 않는다. 고정점 오염은 방어 목표, 금빛 표적은 공격 목표, 취약 균열은 빌드 대응 시험이므로 행동이 달라진다.

경로 결정은 3개 중 하나다: **안정 보급**(즉시 REWRITE 1, 낮은 위협), **엘리트 봉합**(위험한 적+유물), **금지 균열**(INTEGRITY 10 선지불 또는 압력 증가, Anomaly 보상). 플레이어는 경로의 위험과 보상을 선택 전 보며, 선택 후 15초 동안 스킬/고정점 준비 시간을 갖는다. 별도 전체 맵 이동·상점은 필요하지 않다. 이 한 화면의 계약 선택으로 런 경로 선택 원리를 구현한다.

## 21. Risk / Reward

| 선택 | 위험 | 성공 보상 | 실패 결과 |
|---|---|---|---|
| **엘리트 봉합** | Ward+Channeler 조합, 고정점 채널 강화 | 유물 3택1, REWRITE 1 | 유물 없음, 압력 +12. 런은 계속됨. |
| **금지 균열** | INTEGRITY 10 선지불, 적응 개체 비중 일시 +10%p | Forbidden Item 2택1 | 선지불 복구 없음, 대신 일반 보상 1개는 보장. |

압력은 0–100, 실패/선택 위험으로 상승하고 위협을 끊으면 감소한다. 40 초과부터 적 조합이 변하며 60 초과부터 INTEGRITY가 `0.0125 × (압력−40)`/초 감소하는 것을 초기값으로 둔다. 이 수치는 실험값이며 HUD에 예측 손실을 표시한다. 위험 보상은 플레이어가 고른 위험 또는 실수 후의 재도전으로 발생한다. 일부러 체력을 10%까지 낮춰 수동 피해 배수를 극대화하는 구조는 없다.

압력은 채널링이 없는 상태가 8초 이어지면 초당 1씩 감소한다. 따라서 고정점 위협을 빠르게 끊는 행동이 실패 누적을 실제로 회복한다.

## 22. Relic / Special Item System

**일반 레벨 선택**은 빌드의 문법, **METHOD**는 발동 규칙, **RELIC**은 런 전체의 규칙, **ANOMALY/FORBIDDEN**은 강력한 대가를 가진 변형이다. 유물 슬롯 2개, 금지 아이템은 그중 1칸을 차지한다. 같은 유물 중복은 금지. 새 유물을 얻었는데 슬롯이 차면 하나를 교체하거나 거절한다. 첫 런에도 보스 뒤 유물 1개를 경험하게 한다.

| 보상 | 실제 규칙 변화 | 대가/역할 |
|---|---|---|
| `Memory Glass` (Relic) | 최근 5초 안에 직접 삭제를 썼다면 마지막 지정 위치에 약한 메아리 1회 | 계속 자동으로만 플레이하면 발동하지 않음. 처치 VOID 규칙은 다른 공격과 동일. |
| `Borrowed Gravity` (Relic) | 가장 가까운 고정점에 짧은 중력 우물 생성 | 적이 그 고정점 쪽으로 모여 방어 판단 필요. |
| `Crossed Wires` (Relic) | 전도와 소환 신호가 서로의 표식을 한 번 재사용 | 한 뿌리당 1회; 네트워크 빌드의 연결자. |
| `Mercy Protocol` (Relic) | 처음으로 무결성이 25 아래로 내려가면 고정점 1개를 복구 | 발동 후 소멸하는 방어 선택. |
| `Deferred Death` (Forbidden) | 직접 삭제가 즉시 처치하지 않고 3초 후 큰 폭발 예약 | 3초간 채널러를 즉시 끊지 못함. |
| `Open Circuit` (Forbidden) | 전도가 막힐 때 다른 출구를 찾아 재시동 | CHAIN HEAT가 더 빨리 차 과부하 타이밍 관리 필요. |

`Anomaly`는 카드의 희귀도 이름이 아니라 특별 보상 **획득 사건**이다. 프리즘 생명체 같은 목표는 보상 출처이고, 보상층은 Method/Relic/Forbidden 중 하나로 명확히 보여준다. 컬렉션 화면은 미발견 유물의 이름만 잠그고, 발견 조건은 해금 뒤 알려준다.

| **13분: Seal Architect** (엘리트 지휘자) | 현재 주력 태그에 대응하는 작은 봉합 장치 2개와 일반 적 조합. 적응 규칙 읽기 시험. | 보조 태그 또는 세계가 드러낸 균열을 공격하면 장치가 멈춤. | Evolution II 코어, REWRITE 1. |
| **18분: Reality Engine** | 3단계: ① 고정점 동시 채널 예고, ② 플레이어 주력 경로 일부 봉합+반대 약점 창, ③ 30초 동안 코어 이동/교차선. 시간 120초. | 매 단계에 직접 삭제로 열 수 있는 범용 균열 1개. 하이브리드/Final은 더 빠른 해법이나 필수 열쇠는 아님. | 승리 정산, 새 규칙 해금. |

보스 HP는 빌드의 순간 공격력에 비례해 조용히 크게 늘리지 않는다. 보스 기준 목표는 평균 빌드 60–90초, 고숙련/완성 빌드 35–60초, 어려움 빌드 최대 120초다. 시간이 부족한 이유가 **읽지 못한 기믹**인지 단순 피해 부족인지 전투 로그로 구별한다. 보스에는 감염·전도·소환 피해가 모두 적용되고, 지나친 연쇄만 뿌리당 상한으로 제어한다. 최종 보스의 대응은 이미 예고된 적응 규칙을 변주하며 런 끝에 전혀 새로운 면역을 만들지 않는다.

## 24. Meta Progression

메타 재화 **MEMORY**는 런에서 *무엇을 시도했는가*로 얻는다. 초기 정산안: 전투 4분 단위 도달마다 1(최대 4), 첫 적응 대응 성공 2, 중간 보스 2, 새로운 하이브리드 첫 발견 1, 최종 승리 5. 같은 사건의 반복 파밍은 한 런 한 번만 계산한다. 실패해도 달성한 사건의 MEMORY를 받으며, 2분 전 자발적 중단에는 재화 0·발견 기록만 저장한다. 기본 피해/체력 영구 상승은 두지 않는다.

**해금 순서:** 첫 1–3런에 6개 기본 태그와 첫 3개 시작 코어를 모두 노출한다. 4–10런에는 나머지 스킬·분기·유물·적 사건을 넓힌다. 이후 승리/도전 과제로 금지 아이템, 적응 변이, 새 시작 코어, 난도 계약을 연다. 새 적은 보상 가능한 대응 카드/설명과 함께 해금한다. 해금은 카드 출현권을 열 뿐 특정 카드의 획득을 보장하지 않는다. 코어 예시는 `Spark`(전도 1점, 긴 직접 삭제 간격), `Seed`(감염 첫 씨앗, 짧은 자동 범위), `Relay`(드론 1기, 직접 삭제 충전 1개)로 강점과 제약이 모두 다르다.

**저장 명세:** `profileVersion`, `memory`, `unlocks[]`, `discoveries[]`, `challengeClears`, `bestRecords`, `settings`, `processedRunIds[]`를 저장한다. 런 종료는 승리·실패·중단 모두 `finalizeRun(runId, outcome, milestones)` 한 경로를 거친다. 중복 호출은 `runId`로 한 번만 정산한다. 결과 계산 → 유효성 확인 → 로컬 저장 → 결과 화면 순으로 처리한다. 깨진 저장은 전부 삭제하지 않고 이전 버전 백업/마이그레이션을 시도하며, 최소한 해금·재화를 보존한다. 진행 중 런 복구는 첫 출시에서는 요구하지 않지만, 갑작스러운 탭 종료가 승리 정산을 잃지 않도록 결과 저장은 화면 전환보다 먼저 완료한다. 브라우저 로컬 저장만 지원하는 동안 기기 간 동기화는 제공하지 않는다.

## 25. Replayability

**10판 무렵:** 6가지 주력 방향, 시작 코어·스킬 분기의 교차, 첫 하이브리드 발견이 매 판 달라진다. 한 번에 모든 카드를 열지 않아 신규 카드의 문법을 이해할 시간을 준다. **20판 무렵:** 금지 아이템/월드 변이와 난도 계약으로 익숙한 빌드의 약점이 달라진다. **50판 이후:** 높은 난도 계약 조합, 숨은 진화 단서, 최종 보스 변형, 일일 시드(선택 모드)로 숙련 목표를 제공한다. 해금 수를 늘리기 위한 밋밋한 카드 100개보다 의미 있는 조합 20개를 우선한다.

`CHALLENGE`는 특정 행동 제약(예: 직접 삭제 1충전, 유물 1칸)을 걸고 고유 코어/유물을 해금한다. `ASCENSION`은 전체 난도를 단계별로 올리되 보상 확률보다 새로운 적 조합과 보스 변형을 여는 축이다. `DAILY SEED`는 동일 시작 카드/사건/적응 후보를 제공해 비교 가능한 재도전을 만들되 계정 필수 기능으로 삼지 않는다. 숨은 보스는 일반 승리 뒤에만 열리고 표준 20분 완주에 필수는 아니다.

## 26. Difficulty Progression

**전장 위협 예산**으로 난도를 관리한다. 초기안 `B(t)=6+1.1×전투분+2×적응단계+3×선택한 위험계약`이며 Drifter 비용 1, 역할 적 3, 엘리트 10. 예산은 한 순간의 동시 역할 조합을 정하고, 동시 적 수는 별도 180 상한을 지킨다. 보스 전후 20초의 회복 구간에서는 예산을 25% 낮춘다. 월드 티어를 삭제 수만으로 밀지 않는다. 시간은 최소 바닥 위협, 플레이어 선택 계약은 추가 위험, 적응은 역할 변형을 담당한다.

난도 상승 순서는 **새 동작 → 조합 → 빈도 → 제한적 HP**다. HP만 크게 올라간 세포가 성장체감을 지우지 않게 일반 적 HP는 기본 난도 기준 1분당 최대 약 8% 증가 초기 상한을 둔다. 숙련 난도에서는 선택한 `Heat` 계약 한 개마다 별개의 규칙을 더한다: 채널 예고 0.3초 단축, 엘리트 1역할 추가, REWRITE 시작 1 감소 등. 한 계약이 특정 태그를 전면 무효화해서는 안 된다. 난도 보상은 신규 사건/변형 해금과 기록 표시를 우선하고, 일반 런의 모든 강한 카드가 고난도 뒤에 잠기지 않게 한다.

**동적 완충:** 75초 이상 레벨 선택이 없고 VOID 획득 속도가 해당 시점 기준의 절반 아래면 고가치 적 한 무리를 예고해 투입한다. 보상을 받으려면 실제로 처치해야 한다. INTEGRITY가 빠르게 떨어질 때 새 적응 이벤트는 30초 지연하지만 적을 몰래 약하게 만들지는 않는다. 완충 발동은 런 로그에 기록해 밸런스 데이터를 오염시키지 않게 한다.

## 27. Anti-Grind 설계

| 노동감 원인 | 시스템 해결 | 관찰 지표 |
|---|---|---|
| 계속 클릭해야만 자원이 나옴 | 약한 기본 자동 펄스와 모든 처치의 동일 VOID 규칙. 직접 삭제는 2충전·명확한 타이밍 도구. | 분당 클릭 수가 커져도 성장량이 무한 증가하지 않음. |
| 레벨업해도 달라지지 않음 | 첫 90초 메커닉 보장, 세 선택에 비수치 카드 1장 이상. 신규 동작을 시험할 표적 자동 제시. | 신규 카드 후 30초 내 발동 경험률. |
| 빌드가 완성되면 관전만 함 | 고정점 위협, 약점 창, 네트워크 교차점 재배치, 보스 연결선. | 후반에도 의미 있는 직접 명령/스킬 사용. |
| 숫자만 무한 증가함 | HP 성장 상한, 적 역할·배치·적응으로 위협 상승. 피해 배수보다 행동 규칙 진화. | 4분마다 새로운 적 대응 방식 관찰. |
| 랜덤이 빌드 의도를 무시함 | 태그 가중치, REWRITE 2–4회, 진화 시점 보장, 희귀 Pity. | 주력 빌드 방향을 5분 전에 설명할 수 있음. |
| 자동 공격이 노동 면제 보상처럼 보임 | 자동 펄스는 시작 장비, SWARM은 **표적 지휘**라는 새 숙련을 추가. | SWARM 선택 후 조작 질이 결과에 영향. |

**한 런의 감정 곡선:** 0–2분 약함→첫 발견, 2–5분 시동 성공, 5–7분 압도감, 7–8분 보스 긴장, 8–10분 진화 해방, 11분 봉합으로 위기, 12–14분 약점 발견/재조정, 15–17분 완전체, 18–20분 최종 시험. 계속 상승하지 않고 약 3–4분마다 긴장과 해방이 교대한다. 압박은 플레이어가 배운 규칙으로 풀 수 있어야 한다.

## 28. UI / Feedback에 필요한 정보

**상시 HUD:** 좌상단 INTEGRITY/압력과 세 고정점 상태, 중앙 VOID/다음 선택까지 예상 시간, 우상단 현재 1–2개 적응과 **노출 약점**, 하단 E/Q 쿨다운·직접 삭제 2충전·REWRITE, 커서 주변 범위/충전 예고. CHAIN HEAT는 연쇄 빌드에서만 크게 보이고 나머지 빌드에서는 작은 아이콘으로 줄인다. 30초 전 적응 예고는 `관찰한 경로 → 예상 봉합 → 생기는 균열` 세 줄로 표시한다.

**선택 화면:** 카드명·희귀도보다 먼저 “새로 할 수 있는 행동”을 한 문장으로 쓴다. 현재 보유 태그, 충족/미충족 진화 조건, 하이브리드 후보, REROLL/BAN/LOCK 잔량, 선택 후 예상 발동 출처를 보여준다. 숫자 변경은 실제 계산식과 일치해야 한다. 발동 불가 카드와 없는 스탯 키는 콘텐츠 검증에서 금지한다.

**전투 피드백:** 전도선/감염/중력/포격은 색뿐 아니라 선 모양·아이콘·짧은 텍스트가 다르다. 적응체에는 저항과 동시에 약점 표식을 붙인다. 유물/하이브리드 첫 발동은 작은 명칭 표기 1회 후 조용해진다. 화면 효과가 많아도 우선 목표 예고·고정점 채널·보스 약점이 가장 위에 그려진다. ESC에는 최근 30초 피해 원인 비중, 현재 시너지의 `발동→결과`, 획득 순서, 세계가 관찰하는 주력 태그를 제공한다. 런 종료 화면은 승리/패배 원인과 누락된 대응 기회를 보여준다.

**접근성:** 색각 대체 패턴, 화면 흔들림·섬광·오디오 개별 강도, 큰 커서, 정지 가능한 선택 화면, 툴팁 고정, 키 재설정을 초기 지원 범위로 잡는다. 자동 펄스가 있어 손가락 부담 없이 런을 완주할 수 있어야 한다.

## 29. 시스템 연결도

```text
적/고정점 위협 ──> 커서 지정 + 직접 삭제 + E/Q 스킬
       │                         │
       └── 처치 ──> VOID ──> 일반 3택1 ──> 메커닉/태그/시너지
                                   │                │
               우선 목표 ──> REWRITE ──> 선택지 조정 ──┘
                                   │                │
               보스/시련 ──> 진화 코어 ──────────────┤
               엘리트/계약 ──> 유물/금지 아이템 ────┤
                                                    ↓
                                           빌드 행동·처치 경로
                                                    ↓
                             최근 45초 전투 기록 → 세계 관찰
                                                    ↓
                              예고된 봉합 + 동시 노출된 균열
                                                    ↓
                          대응/재배치 → 보스 시험 → 런 정산
                                                    ↓
                              MEMORY·발견·해금 → 다음 런
```

**개발 데이터 흐름:** 콘텐츠 정의 → 조건 검사 → 선택 풀 → 획득 처리 → 표준 전투 이벤트 → 발동 로그/피드백 → 적응 텔레메트리 → 다음 적 변형. 표시 카드와 실제 효과가 같은 정의를 읽는다. 이 흐름에서 효과 처리기가 없는 카드, 수치 키가 없는 카드, 획득 조건을 만족할 수 없는 카드는 빌드 단계에서 실패해야 한다.

## 31. 개발 단계별 Roadmap

각 단계는 **플레이 가능한 종료 조건**을 가진다. 앞 단계가 안정되기 전에 콘텐츠 수만 늘리지 않는다. 기존 HTML은 아이디어·효과 시연의 참조로 쓰되, 상태/데이터 경계는 새로 정리한다.

| Phase | 구현할 것과 완료 기준 | 미뤄도 되는 것 |
|---|---|---|
| **1. 코어 플레이** | 커서 자동 펄스·2충전 직접 삭제·3 고정점·INTEGRITY·기본 적 3종·20분 타이머. 2분 동안 홀드 연타 없이 목표를 지킬 수 있고 실패 원인이 보인다. | 유물, 하이브리드, 메타, 적응. |
| **2. 성장/선택 엔진** | VOID 이월, 3택1, 단일 콘텐츠 정의/효과 검증, REWRITE 조정, 첫 메커닉 보장. 카드 설명/실제 효과가 일치한다. | 희귀 유물 다수, BAN 고급 UI. |
| **3. 6빌드 최소 세트** | 각 빌드 Base 메커닉 2개와 핵심 액티브, 적 역할 6종. 5분 전 각 빌드의 행동을 설명할 수 있다. | Final 전부, 15 하이브리드. |
| **4. 시너지/진화** | 초기 10 하이브리드 중 우선 4개, 6스킬 Branch/Modifier/I/II/Final, 8·13·16분 진화 보상. 한 런에서 Final 도달 확인. | 숨은 진화, 금지 아이템 다수. |
| **5. 세계 적응** | 45초 텔레메트리, 예고 UI, 6개 대응/약점 중 우선 3개, 두 활성 상한. 주력 빌드를 막아도 보조/약점으로 회복 가능하다. | 고난도 변이. |
| **6. 보스/사건/위험** | 8분 중간·13분 지휘자·18분 최종 보스, 사건 스케줄러, 3경로 계약, 유물 6개. 20분 전체 런 완주/패배 가능. | 별도 상점, 숨은 보스. |
| **7. 메타/품질** | 단일 정산 저장, 해금, 결과 분석, 접근성, 밸런스/성능 계측. 30회 시드 런에서 진화 도달/카드 유효성/저장 중복 문제 없음. | 일일 시드, 온라인 기록/클라우드. |

단계별 자동 검증은 “획득 가능한 모든 카드가 실제 발동 처리기를 갖는가”, “모든 진화가 일반 런 시간 안에 도달 가능한가”, “동일 런 종료를 두 번 처리해도 MEMORY가 한 번만 지급되는가”, “모든 빌드가 기본 난도 보스를 통과할 공통 대응을 갖는가”에 집중한다. 수치 스냅샷을 그대로 확인하는 형식적 테스트보다 연결 오류를 찾는 검증을 우선한다.

밸런스 리뷰는 적 처치 수만 보지 않는다. **첫 새 행동까지의 시간, 빌드별 수동 명령 수와 성공률, 적응 예고를 보고 약점을 사용한 비율, 보스 패턴별 실패 원인, 진화 도달률, 런 종료 저장 성공률**을 함께 본다. 어떤 시스템이 플레이어 행동을 바꾸지 않으면 숫자를 올리는 대신 그 시스템의 조건·대상·위치를 다시 설계한다.

## 34. 최종 게임의 완성된 플레이 경험 설명

첫 2분의 플레이어는 커서를 움직여 고정점으로 접근하는 적을 발견하고, 아껴 둔 직접 삭제 한 번으로 작은 전도를 만든다. 레벨업하면 다음 클릭의 결과가 달라지고, 어느 적을 먼저 노려야 하는지 이해한다. 중반에는 자신이 고른 규칙이 결합해 군집을 통째로 무너뜨리는 순간을 경험한다. 바로 그 경로를 세계가 읽고 일부를 봉합하지만, 플레이어는 봉합이 노출한 선 끝·정지한 정화자·이동한 중력 중심을 이용한다. 마지막 2분에는 자동 시스템이 대부분의 작은 적을 처리하는 동안 플레이어가 고정점 방어, 스킬 순서, 교차점 이동, 보스 약점 창을 지휘한다. **같은 커서와 같은 화면이지만 처음에는 점을 지우고 마지막에는 삭제의 법칙을 설계한다.**

완성 판단은 기능 개수가 아니다. 매 시스템을 추가할 때 묻는다: **“이 선택 뒤 플레이어가 실제로 다른 행동을 하는가?”** 답이 아니면 삭제하거나 다른 규칙과 합친다.

# DELETE THE WORLD v2

**모든 것은 삭제될 수 있다.**

세 현실 고정점을 지키며 두 스킬로 삭제 경로를 만드는 커서 지휘 로그라이트입니다. 세계는 피해 속성을 관찰하고 일부 적을 봉합하며, 다른 공격의 균열을 드러냅니다. 원본의 전도·폭발·중력·절단·포격·감염을 새 엔진과 성장 구조로 구현했습니다.

Canvas와 정적 ES 모듈을 사용합니다. 외부 실행 패키지, 이미지, 계정, API 키가 필요하지 않습니다.

## 실행

Windows에서는 **START_GAME.cmd를 더블클릭**하세요. Node.js 또는 Codex의 Node 런타임을 찾아 서버를 숨겨 실행하고 브라우저를 엽니다. 실행기 창이 닫혀도 서버는 유지되며, 다시 실행하면 이미 열린 게임 서버를 사용합니다.

4173 포트가 사용 중이면 실행기가 4174–4193 중 빈 포트를 선택합니다. 자동으로 열린 브라우저 주소를 사용하세요. 저장 데이터는 브라우저와 포트마다 분리됩니다.

Node.js 20 이상에서 저장소 폴더의 터미널을 열고 실행하세요.

```sh
node server.js
```

브라우저에서 **http://127.0.0.1:4173**을 여세요. `npm start`도 같은 명령을 실행합니다. ES 모듈을 사용하므로 `index.html`을 `file://`로 직접 열면 안 됩니다.

`index.html`, `style.css`, `src/`는 상대 경로를 사용하므로 정적 호스팅에서도 실행됩니다. 개발 서버는 로컬 주소에만 바인딩됩니다.

## 화면과 시작 흐름

첫 번째 게임 `DELETE_THE_WORLD_summoner_cross_network(5).html`의 UI를 기준으로 합니다. 검정 전체 화면, 중앙 영문 타이틀, 흰 글자와 보라 네온, 가장자리 HUD, 하단 E/Q 패널을 사용합니다.

**시작 → 모드 설정 → 첫 스킬 선택 → 전투** 순서입니다. 카드 하나를 누르면 바로 시작합니다. 성장 선택과 결과는 전체 화면으로 열리고, ESC에서 일시정지를 확인합니다. 연구와 기록에는 판 종료 후 얻는 **기억**을 사용합니다.

게임 가이드는 **시작 / 성장 / 세계 / 기록** 네 쪽으로 나뉩니다. 각 쪽은 짧은 단계와 카드로 먼저 설명하고, 정확한 수치·전체 사건 시간·특수 입력은 펼친 세부 안내에서 확인합니다. 스킬·분기·변형·성장 카드의 이름은 한국어로 표시하며 전투 판정과 저장용 ID는 유지합니다.

## 가독성 정리

- 상단 **상태**, 좌측 **세계**, 하단 **공격**의 세 구역에 정보를 묶었습니다. 안정도 중복 표시와 상시 서술은 제거했습니다.
- 성장 카드는 짧은 이름과 핵심 효과를 먼저 보여 줍니다. 수치·제약·교체 대상은 **상세 보기**에 보존했습니다.
- 시작 화면과 일시정지의 **게임 가이드**에서 네 분류를 읽고, 화면 구역 그림과 자세한 조건을 펼칠 수 있습니다.
- 참고 자료: [Vampire Survivors 공식 시작 팁](https://store.steampowered.com/app/1794680/Vampire_Survivors/), [Brotato 공식 기능 안내](https://store.steampowered.com/app/1942280/Brotato/). 짧은 시작 행동과 전투·성장 설명 분리를 참고했습니다. 우리 화면의 구역 배치는 이 게임의 고정점과 스킬 입력에 맞춘 구성입니다.

키 지정, 저동작·저효과·고대비 모드, 효과음 음량 설정을 제공합니다. 권장 입력은 데스크톱 마우스와 키보드입니다.

### 먼저 할 일

1. 시작 스킬을 골라 E로 사용하세요. 두 번째 스킬 Q는 기본 **03:30**, 빠른 **01:10**에 선택합니다.
2. 좌클릭으로 중요한 적을 지우세요. 적중할 때 충전 1개를 쓰며, 빗나가면 충전을 쓰지 않습니다. 0.8초 이상 눌렀다 놓으면 강타입니다.
3. 세 고정점 앞의 적색 경고를 보세요. 채널러는 2초 준비 뒤 안정도를 깎습니다. 직접 공격로 채널을 끊고, 안정도가 0이 되기 전에 처치하세요.

### 모드

- **기본:** 18분 세계 진행 + 최종 보스 최대 120초. 성장 선택 중에는 시간이 멈춥니다.
- **빠른:** 같은 사건을 6분으로 압축 + 최종 보스 최대 120초. 처치 경험치도 3배 획득합니다. 재사용 대기와 입력은 실제 시간을 따릅니다.
- **연습:** 스킬·분기·변형·진화·보조 스킬을 골라 연습합니다. 8개 역할 표적 또는 체력 4800의 이동 저항 보스를 사용하고, 표적은 6초마다 보충됩니다. 안정도 손상·성장 선택·기억 정산은 없습니다. 최종 스킬은 하나, 보조 스킬은 2진화 이하입니다.

보스 공통 균열이 열린 동안 직접 공격로 맞히면 예고된 공격과 증원을 함께 막습니다. 최종전은 기본 **18:00**, 빠른 **06:00**에 시작하며, 등장 후 **120초 안에 처치해야 승리**합니다. 남은 중간 보스는 최종 봉합에 흡수되고 위협이 12 오릅니다.

## 콘텐츠

| 시스템 | 구현 |
| --- | --- |
| 시작 코어 | 6개, 각 보너스와 대가 |
| 스킬 | 전도, 폭탄, 블랙홀, 절단, 포격, 감염 |
| 변화 | 각 스킬의 분기 2개, 특수 변형 2개, 진화 3단계 |
| 최종 | 살아있는 회로, 기록 폭발, 현실 접기, 회전 절단, 십자망, 감염 확산 |
| 빌드 | 속성 6개, 특성 12개, 조합 10개, 속성 최종 2개 |
| 유물 | 6개, 최대 2슬롯, 명시적 교체 |
| 적과 보스 | 적 역할 8개, 우선 목표, 계약, 시련, 보스 3종 |
| 성장 | 경험치, 다시 쓰기, 카드 제외, 진화 코어, 위험 계약 |
| 기록 | 기억, 기초 연구 2종, 발견 기록, 최근 15판 |

성장은 **분기 → 특수 변형 → 1진화 → 2진화 → 최종** 순서입니다. 중간 보스와 균열 시련의 목표를 **처치해야** 진화 코어를 받습니다. 코어는 누락된 분기와 변형을 채운 뒤 진화를 올립니다. 스킬 최종에는 해당 속성 4점과 **실제 적중한 시전 8회**가 필요하며, 속성 최종을 포함해 **한 판에 최종은 하나**입니다. 조건이 모자란 코어는 최종전 직전까지 보관하고, 이후 가능한 진화나 유물로 바뀝니다.

특성은 해당 속성 4점과 발동 수단을 갖추면 나타납니다. 조합은 두 속성이 각각 4점이고 필요한 스킬·효과를 갖추면 선택할 수 있으며 판당 하나입니다. 세계 저항을 받은 일부 적은 해당 속성 피해가 25% 줄어드는 대신 표시된 약점 속성 피해가 30% 늘어납니다. 기본은 30초, 빠른은 10초 전에 봉합을 예고합니다.

## 연구와 기억

판 결과의 기억을 연구에 사용합니다. **충전 회복**은 단계당 직접 공격 충전 회복 속도 +2%, **시작 경험치**은 단계당 시작 경험치 +4입니다. 각각 최대 5단계이며 비용은 `5 + 현재 단계×3` 기억입니다. 연구 보너스는 다음 판 시작에 적용됩니다.

기본 기억 획득량은 `삭제 35개당 1 + 지속 90초당 1 + 승리 보너스 12`입니다. 승리·삭제 5개·지속 20초 중 하나를 충족하면 최소 1을 받고, 아주 짧은 무처치 판과 실험실은 기억을 얻지 않습니다.

## 저장

기록·연구·설정은 **현재 브라우저와 사이트 주소의 localStorage**에 저장됩니다. 다른 브라우저나 주소에서는 공유되지 않습니다. 저장 공간이 차단되면 플레이는 가능하며 결과 화면에서 저장 실패를 알립니다. 손상된 선택 저장 필드를 복구하고 판 정산 중복을 방지합니다.

시드는 난수 출발점을 재현합니다. 동일한 결과에는 같은 입력 순서와 타이밍도 필요합니다. 온라인 계정 동기화나 서버 순위표는 포함하지 않습니다.

## 검증

```sh
node --test
node scripts/check.js
```

`npm test`, `npm run check`도 지원하며 GitHub CI에서 같은 검사를 실행합니다. 실제 엔진의 피해·스킬·Final·성장·저장·전체 일정과 렌더 상태 무변경을 검사합니다. 전체 일정 테스트는 일정 확인을 위해 남은 적을 제거하므로 승률 측정에 사용하지 않습니다.

실제 수치와 입력만 사용하는 별도 자동 플레이:

```sh
node scripts/balance-sim.js --mode=expedition --seeds=211029,42,6001 --policy=power --output=reports/balance-final-report.json
```

이 봇은 특정 조준·성장 정책의 회귀 도구입니다. 순간적인 조준, 불완전한 범위 선택 등 사람과 다른 행동을 하므로 사람의 승률·재미를 대신하지 않습니다. 결과는 `reports/balance-final-report.json`을 확인하세요.

# DELETE THE WORLD v2

**모든 것은 삭제될 수 있다.**

지구처럼 생긴 행성 3개를 지키며 동그란 적 행성에 두 능력을 펼치는 로그라이트입니다. 세계는 피해 속성을 관찰하고 일부 적에 저항과 약점을 만듭니다. 전도·폭발·중력·절단·포격·감염, 성장과 최종 진화는 유지하며 필드의 변화가 먼저 보이도록 구성했습니다.

Canvas와 정적 ES 모듈을 사용합니다. 외부 실행 패키지, 이미지, 계정, API 키가 필요하지 않습니다.

## 우주 비주얼

남색·인디고·보라 성운, 작은 별빛과 느린 우주 먼지로 전장을 구성합니다. 행성의 대기광과 궤도 입자는 역할 색을 유지하며, 실제 타격에는 빛의 파동과 파편, 파괴에는 짧은 섬광이 발생합니다. 스킬 코어는 실제 사용 기록에 반응하고 재사용 시간이 줄어들수록 빛이 충전됩니다. 공격 범위, 버튼 위치, 성장과 전투 규칙은 그대로입니다. 설정의 동작 줄이기·효과 줄이기를 적용하면 장식 움직임과 추가 입자를 줄입니다.

## 실행

Windows에서는 **START_GAME.cmd를 더블클릭**하세요. Node.js 또는 Codex의 Node 런타임을 찾아 서버를 숨겨 실행하고 브라우저를 엽니다. 실행기 창이 닫혀도 서버는 유지되며, 다시 실행하면 이미 열린 게임 서버를 사용합니다.

4173 포트가 사용 중이면 실행기가 4174–4193 중 빈 포트를 선택합니다. 자동으로 열린 브라우저 주소를 사용하세요. 저장 데이터는 브라우저와 포트마다 분리됩니다.

Node.js 20 이상에서 저장소 폴더의 터미널을 열고 실행하세요.

```sh
node server.js
```

브라우저에서 **http://127.0.0.1:4173**을 여세요. `npm start`도 같은 명령을 실행합니다. ES 모듈을 사용하므로 `index.html`을 `file://`로 직접 열면 안 됩니다.

`index.html`, `style.css`, `src/`는 상대 경로를 사용하므로 정적 호스팅에서도 실행됩니다. 개발 서버는 로컬 주소에만 바인딩됩니다.

## 화면과 시작 흐름

검은 우주, 먼지와 성운, 동그란 적 행성과 지구 3개가 화면을 이룹니다. 터미널 글꼴과 네온 사각 패널을 없애고, 위에는 작은 삭제 수와 성장 막대, 아래에는 능력의 심볼과 원형 재사용 표시만 띄웁니다. 지구는 평소 파란 바다와 대륙을 보이며, 공격받을 때만 붉게 깜빡입니다. 공격 예고로 위험을 읽습니다.

전장은 화면 안에 같은 비율로 맞춥니다. 창 크기가 달라져도 행성과 공격 범위가 원형으로 유지되며, 클릭 위치도 같은 전장 좌표로 변환됩니다.

**시작 → 모드 설정 → 첫 스킬 선택 → 전투** 순서입니다. 카드 하나를 누르면 바로 시작합니다. 성장 선택과 결과는 전체 화면으로 열리고, ESC에서 일시정지를 확인합니다. 판 종료 후 얻는 **기억**으로 영구 업그레이드를 강화하고, 지난 플레이 기록을 확인합니다.

게임 가이드는 **시작 / 성장 / 세계 / 기록** 네 쪽으로 나뉩니다. 각 쪽은 짧은 단계와 카드로 먼저 설명하고, 정확한 수치·전체 사건 시간·특수 입력은 펼친 세부 안내에서 확인합니다. 스킬·분기·변형·성장 카드의 이름은 한국어로 표시하며 전투 판정과 저장용 ID는 유지합니다.

## 세계 중심 UI와 조준

- 평소에는 **레벨·경험치·삭제 수·E/Q**만 작게 표시합니다. 안정도·위협·세계 저항·빌드·피해 통계는 ESC에 있습니다. 보스 체력과 연쇄 과열은 필요할 때 나타납니다.
- 능력은 **스킬 키 → 필드 미리보기 → 마우스로 조절 → 클릭 확정**입니다. 우클릭 또는 ESC로 취소하면 자원을 쓰지 않습니다. 키를 놓아도 조준은 유지됩니다.
- 슬롯에는 심볼·키·진화 점·원형 회복만 보입니다. 스킬의 수치와 규칙은 일시정지에서 펼쳐봅니다.
- 성장 카드는 이름·핵심 효과·영향받는 스킬을 먼저 보여 줍니다. 정확한 수치와 제약은 **상세 보기**, 교체할 유물은 선택 전에 보입니다. 희귀도는 작은 색으로 표시합니다.
- 적은 모두 동그란 행성이며, 초반의 단순한 원에서 고리와 아우라를 지닌 적으로 발전합니다. 일반 적을 포함한 모든 적에 체력 막대를 표시합니다. 특수 적과 보스는 중요도에 따라 붉은색·무지개색으로 구별합니다. 전도는 연결과 이동, 폭탄은 압축과 충격파, 중력은 입자 흡입, 절단은 공간 균열, 포격은 외부 착탄으로 구별합니다.
- 시작 화면과 일시정지의 **게임 가이드**에서 네 분류를 읽고, 화면 구역 그림과 자세한 조건을 펼칠 수 있습니다.

### 먼저 할 일

1. 시작 스킬을 골라 E로 조준하고 클릭해 사용하세요. 두 번째 스킬 Q는 기본 **03:30**, 빠른 **01:10**에 선택합니다.
2. 좌클릭으로 중요한 적을 지우세요. 적중할 때 충전 1개를 쓰며, 빗나가면 충전을 쓰지 않습니다. 0.8초 이상 눌렀다 놓으면 강타입니다.
3. 세 행성 앞의 적색 경고를 보세요. 채널러는 2초 준비 뒤 안정도를 깎습니다. 직접 공격으로 채널을 끊고, 안정도가 0이 되기 전에 처치하세요.

### 모드

- **기본:** 18분 세계 진행 + 최종 보스 최대 120초. 성장 선택 중에는 시간이 멈춥니다.
- **빠른:** 같은 사건을 6분으로 압축 + 최종 보스 최대 120초. 처치 경험치도 3배 획득합니다. 재사용 대기와 입력은 실제 시간을 따릅니다.
- **연습:** 스킬·분기·변형·진화·보조 스킬을 골라 연습합니다. 8개 역할 표적 또는 체력 4800의 이동 저항 보스를 사용하고, 표적은 6초마다 보충됩니다. 안정도 손상·성장 선택·기억 정산은 없습니다. 최종 스킬은 하나, 보조 스킬은 2진화 이하입니다.

보스 공통 균열이 열린 동안 직접 공격으로 맞히면 예고된 공격과 증원을 함께 막습니다. 최종전은 기본 **18:00**, 빠른 **06:00**에 시작하며, 등장 후 **120초 안에 처치해야 승리**합니다. 남은 중간 보스는 최종 봉합에 흡수되고 위협이 12 오릅니다.

## 콘텐츠

| 시스템 | 구현 |
| --- | --- |
| 시작 코어 | 6개, 각 보너스와 대가 |

성장은 **분기 → 특수 변형 → 1진화 → 2진화 → 최종** 순서입니다. 중간 보스와 균열 시련의 목표를 **처치해야** 진화 코어를 받습니다. 코어는 누락된 분기와 변형을 채운 뒤 진화를 올립니다. 스킬 최종에는 해당 속성 4점과 **실제 적중한 시전 8회**가 필요하며, 속성 최종을 포함해 **한 판에 최종은 하나**입니다. 조건이 모자란 코어는 최종전 직전까지 보관하고, 이후 가능한 진화나 유물로 바뀝니다.

특성은 해당 속성 4점과 발동 수단을 갖추면 나타납니다. 조합은 두 속성이 각각 4점이고 필요한 스킬·효과를 갖추면 선택할 수 있으며 판당 하나입니다. 세계 저항을 받은 일부 적은 해당 속성 피해가 25% 줄어드는 대신 표시된 약점 속성 피해가 30% 늘어납니다. 기본은 30초, 빠른은 10초 전에 봉합을 예고합니다.

## 업그레이드와 기억

판 결과의 기억을 업그레이드에 사용합니다. **빠른 충전**은 강화 단계당 직접 공격 충전 회복 속도 +2%, **시작 보너스**는 강화 단계당 시작 경험치 +4입니다. 각각 최대 5단계이며 비용은 `5 + 현재 단계×3` 기억입니다. 강화 효과는 다음 판 시작에 적용됩니다.

기본 기억 획득량은 `삭제 35개당 1 + 지속 90초당 1 + 승리 보너스 12`입니다. 승리·삭제 5개·지속 20초 중 하나를 충족하면 최소 1을 받고, 아주 짧은 무처치 판과 실험실은 기억을 얻지 않습니다.

## 저장

기록·업그레이드·설정은 **현재 브라우저와 사이트 주소의 localStorage**에 저장됩니다. 다른 브라우저나 주소에서는 공유되지 않습니다. 저장 공간이 차단되면 플레이는 가능하며 결과 화면에서 저장 실패를 알립니다. 손상된 선택 저장 필드를 복구하고 판 정산 중복을 방지합니다.

시드는 난수 출발점을 재현합니다. 동일한 결과에는 같은 입력 순서와 타이밍도 필요합니다. 온라인 계정 동기화나 서버 순위표는 포함하지 않습니다.

`npm test`, `npm run check`도 지원하며 GitHub CI에서 같은 검사를 실행합니다. 실제 엔진의 피해·스킬·Final·성장·저장·전체 일정과 렌더 상태 무변경을 검사합니다. 전체 일정 테스트는 일정 확인을 위해 남은 적을 제거하므로 승률 측정에 사용하지 않습니다.

실제 수치와 입력만 사용하는 별도 자동 플레이:

```sh
node scripts/balance-sim.js --mode=expedition --seeds=211029,42,6001 --policy=power --output=reports/balance-final-report.json
```

이 봇은 특정 조준·성장 정책의 회귀 도구입니다. 순간적인 조준, 불완전한 범위 선택 등 사람과 다른 행동을 하므로 사람의 승률·재미를 대신하지 않습니다. `reports/balance-final-report.json`은 입력 리디자인 전의 기록입니다. 새 조준 입력은 `tests/targeting.test.js`에서 범위 일치·취소·자원 소모·최종 진화와 월드 좌표 고정을 따로 검증합니다.

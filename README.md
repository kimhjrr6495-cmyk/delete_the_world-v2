# DELETE THE WORLD v2

**작은 결함 하나로 세계를 지워라.**

세 현실 고정점을 지키며 두 스킬로 삭제 경로를 만드는 커서 지휘 로그라이트입니다. 세계는 피해 태그를 관찰하고 일부 적을 봉합하며, 다른 공격의 균열을 드러냅니다. 원본의 전도·폭발·중력·절단·포격·감염을 새 엔진과 성장 구조로 구현했습니다.

Canvas와 정적 ES 모듈을 사용합니다. 런타임 패키지, 외부 이미지, 계정, API 키가 필요하지 않습니다.

## 실행

Windows에서는 **START_GAME.cmd를 더블클릭**하세요. Node.js 또는 Codex의 Node 런타임을 찾아 서버를 숨겨 실행하고 브라우저를 엽니다. 실행기 창이 닫혀도 서버는 유지되며, 다시 실행하면 이미 열린 게임 서버를 사용합니다.

4173 포트가 사용 중이면 실행기가 4174–4193 중 빈 포트를 선택합니다. 자동으로 열린 브라우저 주소를 사용하세요. 저장 데이터는 브라우저와 포트마다 분리됩니다.

Node.js 20 이상에서 저장소 폴더의 터미널을 열고 실행하세요.

```sh
node server.js
```

브라우저에서 **http://127.0.0.1:4173**을 여세요. `npm start`도 같은 명령을 실행합니다. ES 모듈을 사용하므로 `index.html`을 `file://`로 직접 열면 안 됩니다.

`index.html`, `style.css`, `src/`는 상대 경로를 사용하므로 정적 호스팅에서도 실행됩니다. 개발 서버는 로컬 주소에만 바인딩됩니다.

## 조작

| 입력 | 행동 |
| --- | --- |
| 마우스 이동 | 조준, 자동 펄스의 관심 영역 지정 |
| 좌클릭 | 직접 삭제. 충전 2개, 기본 회복 2.8초 |
| 좌클릭 0.8초 홀드 | 강타. 1.2초부터 완충 |
| E / Q | 첫 번째 / 두 번째 스킬 |
| T | ORBITAL Final의 CROSS NETWORK |
| ESC | 시간 정지, 빌드 확인, 설정, 런 종료 |
| 1–4 | 성장 카드 선택 |
| 게임패드 | 오른쪽 스틱 조준, A 삭제, X/Y 스킬, B 네트워크, START 계획 |

키 지정, 저동작·저효과·고대비 모드, 효과음 음량 설정을 제공합니다. 권장 입력은 데스크톱 마우스와 키보드입니다.

### 모드

- **표준 균열:** 18분 세계 진행 + 최종 보스 최대 120초. 성장 선택 중에는 시간이 멈춥니다.
- **단축 탐사:** 같은 사건을 6분으로 압축 + 최종 보스 최대 120초. VOID도 3배 획득합니다. 쿨다운과 입력은 실제 시간을 따릅니다.
- **규칙 실험실:** 스킬·분기·변형·진화·보조 스킬을 골라 연습합니다. 8개 역할 표적 또는 이동 저항 보스를 사용하고, 표적은 6초마다 보충됩니다. 무결성 손상과 보상 정산은 없습니다.

채널러의 2초 준비와 보스의 적색 예고를 읽으세요. 보스 공통 균열을 직접 삭제로 맞히면 예고된 공격과 증원을 함께 막습니다. 최종전은 월드 18분에 시작하며, 미처 삭제하지 못한 중간 보스는 압력으로 흡수됩니다.

## 콘텐츠

| 시스템 | 구현 |
| --- | --- |
| 시작 코어 | 6개, 각 보너스와 대가 |
| 액티브 | OVERCHARGE, VOID BOMB, BLACK HOLE, SCREEN CUT, ORBITAL COMMAND, LATENCY SEED |
| 변화 | 각 스킬의 분기 2개, 특수 변형 2개, 진화 3단계 |
| Final | LIVING CIRCUIT, TOTAL VOID, REALITY FOLD, LAST JUDGEMENT, CROSS NETWORK, EPIDEMIC SCRIPT |
| 빌드 | 태그 6개, 메서드 12개, 하이브리드 10개, 태그 Final 2개 |
| 유물 | 6개, 최대 2슬롯, 명시적 교체 |
| 적과 보스 | 적 역할 8개, 우선 목표, 계약, 시련, 보스 3종 |
| 성장 | VOID, 다시 쓰기, 카드 제외, 진화 코어, 위험 계약 |
| 메타 | MEMORY, 기초 연구 2종, 발견 기록, 최근 15런 |

두 번째 스킬은 월드 3:30에 선택합니다. 8·13분 보스와 16분 시련이 진화 코어를 제공합니다. 한 스킬에 세 코어를 집중하면 Final이 됩니다. 조건은 해당 태그 4점과 **실제 유효 사용 8회**, 한 런에 Final은 하나입니다. 조건이 모자란 코어는 17:30까지 보관합니다.

범위·폭·착탄 위치에 맞춘 예고, 역할별 실루엣, 상태 시간 표시와 약점 글리프를 제공합니다. 저효과 모드에서도 위험·보호선·약점을 유지합니다. 감염 기폭 중복 방지, 피해 스냅샷, 방패 우회 상한, 후속 발동 예산, 포격 잠금, 홀 질량과 붕괴, Final 절단 적중 상한이 실제 전투에 적용됩니다. 적 180개 제한에서도 보스와 중요 시련의 등장 공간을 확보합니다.

## 저장

기록·연구·설정은 **현재 브라우저와 사이트 주소의 localStorage**에 저장됩니다. 다른 브라우저나 주소에서는 공유되지 않습니다. 저장 공간이 차단되면 플레이는 가능하며 결과 화면에서 저장 실패를 알립니다. 손상된 선택 저장 필드를 복구하고 런 정산 중복을 방지합니다.

시드는 난수 출발점을 재현합니다. 동일한 결과에는 같은 입력 순서와 타이밍도 필요합니다. 온라인 계정 동기화나 서버 순위표는 포함하지 않습니다.

## 검증

```sh
node --test
node scripts/check.js
```

`npm test`, `npm run check`도 지원하며 GitHub CI에서 같은 검사를 실행합니다. 실제 엔진의 피해·스킬·Final·성장·저장·전체 일정과 렌더 상태 무변경을 검사합니다. 전체 일정 테스트는 일정 확인을 위해 남은 적을 제거하므로 승률 측정에 사용하지 않습니다.

실제 수치와 입력만 사용하는 별도 자동 플레이:

```sh
node scripts/balance-sim.js --mode=expedition --seeds=211029,42,6001 --policy=power --output=reports/balance-final-report.json
```

이 봇은 특정 조준·성장 정책의 회귀 도구입니다. 순간적인 조준, 불완전한 범위 선택 등 사람과 다른 행동을 하므로 사람의 승률·재미를 대신하지 않습니다. 결과는 `reports/balance-final-report.json`을 확인하세요.
